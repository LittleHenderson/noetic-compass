Safety and honesty

The rules that stop HELM, and the people building it, from fooling themselves, and the findings where those rules caught a real problem.

The rules

A failed must-hold check is a failure

A hard gate (a must-hold check; if one fails, the whole run counts as a failure) is a must-hold check written before the run: every write has a receipt (the record a saved fact leaves behind, with a fingerprint, so it can be checked later), nothing is invented, a replay gives the same answer, the controls behave. If one fails, the run is a FAILURE, never "a pass with caveats". Examples: the faculties (a mental job HELM can run on an open item, such as asking or verifying) run failed on gate H1 (§7.34); the memory run failed on gate H8 (§7.43); the transformer (the kind of neural network behind most modern AI chat assistants) ear failed gate H-CWFW (§7.90).

Read back before writing

Every fact is read back and checked before it counts as saved. A write that fails the read-back is refused and nothing is saved. Each saved fact leaves a receipt carrying a hash (a fingerprint of a file; change one byte and the fingerprint changes).

The Eye never writes

The Unity Eye (a small watcher that looks over HELM, reports and whispers, and never writes) may report a problem and whisper (a typed nudge from the Eye that HELM may ignore; it never changes a stored fact) a suggestion. HELM may ignore the whisper. In waves (one sealed test round in the HELM-R1 series, with each part on its own switch) 4 and 5 the Eye made 0 writes (§7.77, §7.78). An acting mode is now built behind the switch HELM_EYE_ACT, OFF by default and not licensed (a claim-status word: this exact sentence may be said, nothing wider (NOT LICENSED: it may not be said)): when it is on, the Eye may put back only what the user's own words re-derive, through HELM's own routines, each change recorded with its reason; it never adds a fact or a number, and where nothing supports a value HELM asks (§7.122).

Refuse rather than guess

Missing information gives UNDETERMINED (HELM's honest 'I cannot tell', used when something it needs is missing); unreadable English gives CLARIFY (HELM asking a question instead of guessing, with nothing saved); a step that should not run gets REFUSE from the RPM Gate (HELM's one gate: it lets a step go ahead, sends it to repair, or refuses, and lets the brain say it cannot tell). In each case nothing is saved.

Write audit on the ear

The transformer ear runs in its own process, watched by a file-write audit that allows only its own log. The first run stopped itself when the watcher saw writes made by a library (§7.85).

No one marks their own homework

A custodian (a separate session that builds and seals each exam so the builder never sees it) builds and seals (frozen and fingerprinted before the run, so nothing can be changed after the fact) each exam; a frozen reader (the scoring program, sealed before the run, that alone writes the verdict) writes the verdict; an AI model is not the research governor; only the owner's signed line starts a paid run or moves a claim (CLAUDE.md).

Findings, stated plainly

These are the tests that found real problems. Each one is kept on the record on purpose.

  • HELM's English reader was not safe on real sentences. On 128 sentences other people wrote, it saved 8 stock facts the sentences did not say, for example "no water on hand" for a sentence about someone pulled out of the water (a practice example). The limit was 2. The fix brought it to 0 wrong on a fresh draw, but it is not yet useful (§7.79, §7.81, §7.87).
  • The transformer ear made confident wrong proposals. On kitchen English written by outside LLMs (large language model, a big pretrained text-predicting neural network like those behind chat assistants), two of three trained copies proposed more confident, well-formed, wrong readings than the cap of 2 allowed (2 / 5 / 3). Nothing wrong was saved, because HELM's own checks decide, but the gate failed: FAILURE, EARS_HARMED (§7.90).
  • Passing the check proves form, not truth. An old English model gave 21 confident answers that passed the round trip (turning a checked statement into English and back; the result must equal the start) and were all wrong (§7.80).
  • The Eye's scan found nothing a plain checksum missed on real kinds of file damage; the checksum caught more kinds (§7.81).
  • Process failures. Two GPU (a graphics chip used to train neural networks quickly) jobs ran with no ledger line and no owner sign line (§7.53). A roadmap claimed a cloud-trained valve that was trained on the laptop (§7.50). A download carried the owner's e-mail address in a request header once (§7.79). Each is recorded, not hidden.
  • Growth has failed or been inconclusive in every run so far, so HELM growing its own capacity stays NOT LICENSED (a claim-status word: this exact sentence may be said, nothing wider (NOT LICENSED: it may not be said)) (§7.71).
