Architecture

HELM is a set of small parts, each on its own switch, around one brain that does exact arithmetic. Here is every part, how many learned numbers it has, and what each one is for.

The parts

HELM is built on CAS (the Cognitive Architecture System, the project's framework for describing how any mind works). Its brain holds recipes (a written rule saying how much of each ingredient one unit of an outcome needs), answers with exact arithmetic, and names the limiting reagent (the ingredient that runs out first and so caps how much can be made). Every saved fact leaves a receipt (the record a saved fact leaves behind, with a fingerprint, so it can be checked later); every sentence it says must pass the round trip (turning a checked statement into English and back; the result must equal the start). Scored tests use sealed (frozen and fingerprinted before the run, so nothing can be changed after the fact) exams and run in numbered waves (one sealed test round in the HELM-R1 series, with each part on its own switch). The one place chance is allowed uses saved seeds (a starting number that fixes which random choices a program makes).

A parameter (an adjustable number a model learns) is an adjustable number a model learns. Big AI chat assistants have billions. HELM's licensed brain has dozens. Each part below sits behind a switch, so tests can turn one part off and see what is lost. A part that loses something when switched off earns the status word (the frozen reader's one-word verdict for a part, such as EARNED_KEEP) EARNED_KEEP (a status word meaning that switching the part off made results worse, so it stays). Tests run on synthetic worlds (a made-up test world built by a program, with known right answers) unless they say otherwise.

Retired and stand-in parts

  • helm_brain_22x40.py: a demonstration brain. "22" is 22 baking ingredients and "40" is a parameter count, not CAS's 22 pathways or 40 states. No score (§7.51).
  • The old valve: a learned rule with five weights and one bias, trained on the laptop. The owner ruled it be replaced by a plain written rule (§7.50).
  • Scribe L4, an old small English model: 0 of 98 exact on the sealed set (§7.80).

What HELM is not

  • No foreign pretrained model. Nothing in HELM was downloaded already trained. The transformer ear was trained from scratch; its run checked "0 pretrained files" (§7.90).
  • The transformer never writes. It runs in its own process and shares nothing with the brain. It never writes a number or a name; HELM's name table, exact-number rule and round trip decide, and anything saved is read back first (§7.82).
  • Not a general chatbot. Its world is a kitchen, by design, as a test bed. See the chat question.
  • Not a large language model, and not trained by preference tuning. See what this hub does not have.

How far the language reaches today

An analyst report measured where each piece of the CAS language map really exists. "Ten frames" are the sentence shapes of the ten Noetics (one of ten basic moves a mind makes with Ideas, written ^0 to ^9); "23 fundamentals" are jobs language does, such as saying how much or saying no. The ledger cells cross each fundamental with each Noetic, Domain (one of four levels a thought works at: Principled, Cognitive, Evaluative, Operational) and Register (the tone of an operation: Transcendent, Analytical, Affective or Embodied). "CTT" is the transformer ear; "D4" rows come from the SDG (the CAS Synthetic Data Generator, the project's program for making practice English). The table is copied from the report.
