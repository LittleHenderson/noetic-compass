Results scorecard

Every HELM record in the spec sheet, from the first brain test onward. Failures and weak results stay in the table on purpose: they are what keeps every other claim honest.
Words used on this page, in plain English
CAS
the Cognitive Architecture System, the project's framework for describing how any mind works
Noetic
one of ten basic moves a mind makes with Ideas, written ^0 to ^9
Drive
one of seven core motivations, F1 Unity to F7 Purpose
Domain
one of four levels a thought works at: Principled, Cognitive, Evaluative, Operational
recipe
a written rule saying how much of each ingredient one unit of an outcome needs
recipe brain
HELM's brain made of written recipes and exact arithmetic instead of a neural network
RPM Gate
HELM's one gate: it lets a step go ahead, sends it to repair, or refuses, and lets the brain say it cannot tell
CLARIFY
HELM asking a question instead of guessing, with nothing saved
receipt
the record a saved fact leaves behind, with a fingerprint, so it can be checked later
round trip
turning a checked statement into English and back; the result must equal the start
CCE
Controlled Core English, a strict small form of English that converts to CAS and back exactly
Unity Eye
a small watcher that looks over HELM, reports and whispers, and never writes
whisper
a typed nudge from the Eye that HELM may ignore; it never changes a stored fact
custodian
a separate session that builds and seals each exam so the builder never sees it
sealed
frozen and fingerprinted before the run, so nothing can be changed after the fact
frozen reader
the scoring program, sealed before the run, that alone writes the verdict
hard gate
a must-hold check; if one fails, the whole run counts as a failure
status word
the frozen reader's one-word verdict for a part, such as EARNED_KEEP
EARNED_KEEP
a status word meaning that switching the part off made results worse, so it stays
claim status
what may be said about a result, using only the words of the spec sheet's legend
claim ceiling
the widest world a claim covers; nothing outside it is claimed
SYNTHETIC_ONLY
a claim ceiling: the result holds on made-up test worlds only
NAMED_CORPORA_ONLY
a claim ceiling: the result holds on the named public text collections only
synthetic world
a made-up test world built by a program, with known right answers
LICENSED
a claim-status word: this exact sentence may be said, nothing wider (NOT LICENSED: it may not be said)
VALIDATED
a claim-status word: it passed its own pre-set test against controls, on the data it was measured on
ENGINEERED-NOT-VALIDATED
a claim-status word: built and working, with no validated result yet
wave
one sealed test round in the HELM-R1 series, with each part on its own switch
wide brain
the recipe brain with its ingredient list opened up (any ingredient name, up to 10 per recipe, exact fractions, 20 units), behind a switch; HELM's canonical-brain candidate, not yet canonical
pair wave
wave 6: the wide brain run together with HELM's other parts to read how each pair behaves
chat wave
wave 7: HELM's chat window typed to line by line, with the wide brain on, scored on three fresh exams the builder never sees
CTT
the CAS-token transformer, HELM's optional 'ear': a small translator that proposes a reading only when HELM's own reader would ask, and never writes
transformer
the kind of neural network behind most modern AI chat assistants
parameter
an adjustable number a model learns
LLM
large language model, a big pretrained text-predicting neural network like those behind chat assistants
GB3
the small transformer that used to be HELM's brain and is the bar to beat
AWS
Amazon Web Services, the rented cloud computers used for heavy runs
GPU
a graphics chip used to train neural networks quickly
seed
a starting number that fixes which random choices a program makes
hash
a fingerprint of a file; change one byte and the fingerprint changes
SDG
the CAS Synthetic Data Generator, the project's program for making practice English
restart fallback
if the exact first try leaves something unexplained, a few saved random restarts are tried and the checker decides
cube store
where HELM keeps facts; an unknown side stays marked unknown and is never filled in
triad
three stages on each ingredient: Purpose, Wisdom and Power
cascade
going down into sub-problems, with a stop rule and a depth limit
drive loop
HELM's idle attention moving among the seven Drives toward unfinished work
faculty
a mental job HELM can run on an open item, such as asking or verifying

How to read a row

Each row reads in four layers. Did the run itself hold up (the verdict)? What one word did the scoring program give the part (the status word)? What may be said (the claim status, using only the legend words below)? And how wide is the claim (the ceiling)? The color is the owner's scale and is only a reading aid; this hub's editor chose each row's color from the record, and where the record marks a color itself, the hub uses that one. The "Plain meaning" column is the hub's summary; the record governs.

The claim-status legend

These are the only words allowed for what may be said. One word, one meaning, everywhere. Copied from the spec sheet's §3.

WordMeansDoes NOT mean
REALThe thing exists and runs. Code executes, artifacts are on disk, numbers were produced by a real execution rather than a description of one.That the numbers support any claim about the world. Wired ≠ works.
VALIDATEDIt ran and it passed its own pre-registered criterion, against matched controls. The apparatus does what the apparatus is supposed to do.That the result generalises beyond the fixture, corpus, language, seed, split, or model point it was measured on.
LICENSEDYou may say this sentence out loud, in this exact wording, to a customer or a regulator. The evidence covers the claim as worded.Anything broader than the exact wording. Widening the sentence voids the licence.
NOT LICENSEDYou may not say it. Either the evidence does not exist, or it exists and does not reach the claim.That the claim is false. It means unproven, and sometimes it means untested.
GREYThe test ran, was valid, and returned neither a pass nor a clean refutation. **A GREY is not a pass.**A soft yes. Do not report GREY as encouraging.
VACUOUSThe test could not be read, because a precondition failed — the intervention changed nothing at all, or the controls were mis-dosed, or the readout was below the instrument's resolution. The label was never tested, rather than tested and rejected.A FAIL. Do not average VACUOUS into a pass rate.
WITHDRAWNA claim was made, then retracted, on the record, with a reason code and a date. It stays in this document forever.That it can be quietly revived. Withdrawal is permanent unless a new artifact re-earns it under a new row.
ENGINEERED-NOT-VALIDATEDThe machinery is built and the design is sound, but no result has come out of it. Capacity, not evidence.Anything about performance. "Built for 300B" is not "works at 300B".
FLAG_FOR_HUMAN_REVIEWThe verdict ceiling for an artifact whose checks did not all clear. It is the honest verdict, not a holding pattern.A pending ACCEPT.
PASS / FAILA single pre-registered test met / did not meet its stated criterion. Always report which criterion, and whether it was set before the run.A verdict on the whole battery.
SANITY_PASS / SANITY_FAILA generic control experiment (nothing to do with CAS) showing the measuring instrument can or cannot produce a real, selective effect at all. Held outside any aggregate and outside the verdict, by design.Evidence for or against any CAS hypothesis. It only tells you whether the apparatus is alive.
NULLA pre-registered test ran, was evaluable, and found nothing. An honest empty hand.An error. Nulls are results and are kept.
FALSIFIEDA pre-registered test ran and the hypothesis was refuted, with the control rig catching the failure.A defect. This is the machinery working.
VOIDThe run is unusable for reasons unrelated to the hypothesis (degenerate metric, contaminated fixture, wrong configuration). Numbers from a VOID run may never be cited.A negative result about the hypothesis.
OPENNever run, or run and not yet adjudicated. Untested is not the same as null.That it failed.
unavailableThe fact is unrecoverable from the record. Write the word. Never fill it in with a plausible value — that is fabrication.That it can be looked up later from an external source.
PARTIALThe test ran and returned a real, readable result that reaches part of the claim and not the rest. Always name which part is reached and which is not.A pass with a footnote. A PARTIAL never licenses the full sentence.
