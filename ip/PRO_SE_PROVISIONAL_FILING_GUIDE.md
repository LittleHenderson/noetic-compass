# Pro Se Provisional Filing Guide

This guide is for preparing and filing a **U.S. provisional patent application** without counsel.

It is **not legal advice**. It is a practical filing guide tied to the current project files in this workspace.

- Provisional filing requirements:
  - https://www.uspto.gov/patents/basics/apply/provisional-application
- Patent Center:
  - https://www.uspto.gov/patents/apply/patent-center
- Getting started as a new Patent Center user:
  - https://www.uspto.gov/patents/apply/applying-online/getting-started-new-users
- Patent application forms:
  - https://www.uspto.gov/patents/apply/forms
- Entity status:
  - https://www.uspto.gov/patents/apply/applying-online/entity-status-fee-purposes

## What A Provisional Does

A provisional application can establish a U.S. filing date. It is **not examined** and does **not** turn into a patent by itself.

You generally must file a corresponding nonprovisional within **12 months** if you want to claim the provisional's benefit.

## What A Provisional Does Not Require

USPTO says a provisional does **not** require:

- formal claims
- an oath or declaration
- an information disclosure statement

## What You Must Have Before Filing

For each provisional filing, you need:

1. a written description/specification that is detailed enough to support the later claims you may want;
2. drawings if needed to understand the invention;
3. a provisional cover sheet;
4. the filing fee; and
5. all inventor names and residences for that provisional.

## Step 1: Decide Whether To File One Provisional Or Two

For this project, the practical options are:

- one provisional for **Noetic Compass**
- one provisional for **CAS-native**
- two separate provisionals

Recommended practical path if you can afford it:

- file **two** provisionals

Reason:

- the Noetic Compass system and the CAS-native architecture are related but distinct
- separate filings create cleaner priority records
- separate filings reduce the risk that one abstractness or disclosure problem spills into the other

## Step 2: Create Or Verify Your USPTO Filing Access

### Website path

1. Go to:
   - https://www.uspto.gov/patents/apply/applying-online/getting-started-new-users
2. Create a USPTO.gov account if you do not already have one.
3. Verify your identity.
   - Fast path: ID.me
   - Slower paper path: notarized verification form mailed to USPTO
4. Self-enroll in Patent Center as an **Independent Inventor**.
5. Confirm you can sign in to:
   - https://patentcenter.uspto.gov

Important:

- the **notary** is relevant only if you use the paper identity-verification route for Patent Center access
- the notary is **not** what makes the provisional valid

## Step 3: Practice Once In Patent Center Training Mode

### Website path

1. Go to:
   - https://www.uspto.gov/patents/apply/patent-center
2. Read the Patent Center page.
3. Use **Training mode** first if available in your account interface.

Do this before the real filing so you do not make a preventable upload/payment mistake.

## Step 4: Choose The Filing Order

Recommended order:

1. file the stronger, cleaner provisional first
2. file the second one immediately after if possible

If you must choose just one first:

- file **Noetic Compass** first if the public website is the biggest timing risk
- file **CAS-native** first if architecture novelty is the bigger priority and the public product disclosures are thinner there

## Step 5: Prepare The Actual Filing Documents

### Do upload

For each provisional, prepare:

- specification/detailed description
- drawings/figures if needed
- USPTO provisional cover sheet (SB/16)
- entity-status support if you are claiming a discounted fee and the USPTO requires it

### Do not upload

These are useful internally or for counsel, but are usually **not** filing papers:

- inventorship memos
- internal patent-readiness memo
- counsel cover email
- internal handoff checklists
- disclosure timeline memo
- broad theory documents unless you intentionally want them in the filing record

## Step 6: Get The USPTO Cover Sheet

### Website path

1. Go to:
   - https://www.uspto.gov/patents/apply/forms
2. Find:
   - **Provisional Application for Patent Cover Sheet**
   - `SB/16`
3. Download the current form or use the Patent Center version if filing inside Patent Center.

USPTO says the cover sheet should identify:

- the application as a provisional application
- inventor names
- inventor residences
- title of the invention
- correspondence address
- attorney/agent info if any
- any government interest if applicable

## Step 7: Decide Your Entity Status Before Paying

### Website path

1. Go to:
   - https://www.uspto.gov/patents/apply/applying-online/entity-status-fee-purposes
2. Determine whether you qualify as:
   - undiscounted / large entity
   - small entity
   - micro entity

Important:

- do **not** claim micro entity casually
- if you are not sure, either verify carefully or pay the higher fee

## Step 8: Prepare Your Files In Final Filing Form

For a provisional, USPTO states the application papers can be filed electronically using Patent Center in PDF form.

Recommended file set per provisional:

1. `SPECIFICATION.pdf`
2. `DRAWINGS.pdf` if needed
3. `SB16_COVER_SHEET.pdf` or the Patent Center equivalent
4. any entity-status form if needed for your fee status

Keep file names simple and clean.

## Step 9: File In Patent Center

### Website path

1. Go to:
   - https://patentcenter.uspto.gov
2. Sign in.
3. Start a **new submission**.
4. Select the new submission type corresponding to a provisional utility filing.
   - USPTO materials identify the relevant submission type as:
     - `Utility Provisional or Plant Provisional`
5. Enter the bibliographic information requested in Patent Center.
6. Upload the specification.
7. Upload the drawings if needed.
8. Complete or upload the provisional cover sheet information.
9. Validate the submission inside Patent Center.
10. Pay the filing fee.
11. Submit.

## Step 10: Do Not Leave Without The Receipts

After submission, save:

- the submission receipt
- the payment receipt
- the application number
- the confirmation date/time
- the exact uploaded files

Save them in at least two places.

## Step 11: After Filing

After the provisional is filed:

- you may use `Patent Pending` for that filed invention
- calendar the **12-month** deadline immediately
- do not assume you are done

Create a reminder for:

- 10 months after filing
- 11 months after filing
- 11.5 months after filing

## Step 12: Keep Your Public Statements Tight

After filing:

- do not say “patent granted”
- do not say “fully protected worldwide”
- do not expand the technical story carelessly

You can say:

- “patent pending” only after filing

## Final Warning

A provisional is only as good as its disclosure. A thin provisional can give you a filing date but still fail to support the later claims you actually need.

If you are unsure whether the draft is sufficiently enabling, the best move is still to get a patent attorney to review before filing.
