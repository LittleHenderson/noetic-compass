# The Complete Memory Deck

*One line per part.*

Use the first verb as the mnemonic:

| Part | Electrical verb | Cognitive verb |
|---|---|---|
| Resistor | limit | restrain activation |
| Capacitor | retain | preserve composition |
| Inductor | oppose change | preserve an established pattern |
| Varactor | tune capacitance | tune retention or resonance |
| LC tank | resonate | favor one repeating rate |
| Diode | allow one way | enforce directed admissibility |
| Zener | trip and clamp | enforce a threshold with a ceiling |
| Transformer | convert level | translate across a licensed Domain seam |
| Photodiode | transduce light | admit external Idea content through Mind intake |
| Bridge rectifier | normalize scalar polarity | PED only on a named non-valence scalar |
| CJT | control and amplify | let bias shape trigger into arrival |
| Op-amp | compare | amplify a commensurable difference |
| Differential pair | reject common mode | preserve a matched difference |
| Current mirror | copy bias | share one comparison condition |
| Active load | convert difference | land a branch difference as output |
| Oscillator | repeat | sustain a cycle |
| Crystal | stabilize frequency | hold a low-drift cadence |
| PLL | lock | entrain an internal rhythm |
| AND | require all | detect all-active prerequisites or conflict |
| OR | require any | accept one or more thresholded flags |
| NOT | complement | negate one explicit firing flag |
| NAND | reject all-active | invert an AND result |
| NOR | require none | accept only when every flag is inactive |
| XOR | distinguish | accept exactly one active flag |
| XNOR | agree | detect equal flags, including both-inactive |
| MUX | choose | route one selected input to one output |
| DEMUX | dispatch | send one input to one selected output |
| Relay | isolate and switch | let Cause control a separate Effect path |
| Schmitt trigger | commit and hold | prevent threshold chatter |
| ADC | quantize | translate a continuous Register into discrete form |
| DAC | reconstruct | translate a discrete Register into continuous form |
| Regulator | restore | maintain a setpoint |
| Fuse | sever once | permanently stop an unsafe path for the stated lifetime |
| Circuit breaker | trip and reset | stop a recoverable fault path |
| Drive rail | supply | make motive potential available |
| Reference | define zero | set an engineered baseline |
| Probe | observe | inspect one named point without becoming its signal |
| Switch | connect | enable or inhibit one path |
| Meter | measure | report one named quantity by a named method |
| Net label | name | type the whole state or scalar |
| Solid arrow | advance | show the main forward path |
| Dashed arrow | return | show a sampled feedback path |

This table covers all 42 frozen component and annotation entries. The printable 56-card deck prints 29 of those entries individually, folds five narrow or derived entries into their parent cards — **Varactor** into Capacitor and LC tank, **Current mirror** into Differential Pair, and **NAND**, **NOR** and **XNOR** into the AND/OR/NOT/XOR family — and groups the eight annotation entries into three study families: Supply & Zero, Observe & Name, and Route & Grammar. Nothing is dropped: the chapter plates and Appendix A of this guide retain all 42 individual entries.
