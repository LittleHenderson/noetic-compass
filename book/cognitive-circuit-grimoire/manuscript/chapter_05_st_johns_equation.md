### 5.3 St. John's Equation — The Formula

```
Given an operation (spell cast) with:

  t_op    = duration of the operation (in minutes)
  t_conf  = time until first confirmation (in minutes, from end of operation)

Step 1 — Efficiency Ratio:

  η = t_op / t_conf

Step 2 — Apply the Noetic Time Constant:

  result = η × τ        where τ = 1/3
  result = a / b         (reduce to lowest terms)

Step 3 — Read the Circuit Parameters:

  β_required   = b      (gain required for NEXT operation, relative to this one)
  n_operations = a      (number of operations at ORIGINAL strength needed)
  T_manifest   = a × t_op    (total additional operation minutes needed)
```

**The interpretation:**

- **β_required = b:** Your next operation must deliver **b times** the cognitive activation of this one. If b = 9, you need a CJT with β = 9 — nearly an order of magnitude stronger. If b = 1, your current strength is sufficient.
- **n_operations = a:** You need **a more operations** at the ORIGINAL strength. If a = 1, one more cast suffices. If a = 7, you need seven.
- **T_manifest = a × t_op:** The total additional time you will spend in operations before the desire manifests. For a 20-minute operation with a = 1, that's 20 more minutes. With a = 20, that's 400 minutes.
