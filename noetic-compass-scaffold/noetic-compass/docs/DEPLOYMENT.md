# Deployment Guide

## Local Development (Docker Compose)

```bash
# Copy env template and set API keys
cp .env.example .env

# Start all services
docker compose up --build

# Access:
#   API:       http://localhost:8000
#   Dashboard: http://localhost:3000
#   Health:    http://localhost:8000/health
```

## Cloud Deployment (Render)

### Quick Start
1. Push repo to GitHub
2. Go to [Render Dashboard](https://dashboard.render.com)
3. New > Blueprint > connect your repo
4. Render auto-detects `infra/render.yaml`
5. Set environment variables (API keys) in Render dashboard

### Services Created
| Service | Type | URL |
|---------|------|-----|
| noetic-compass-api | Web Service (Docker) | `*.onrender.com` |
| noetic-compass-dashboard | Static Site | `*.onrender.com` |

### Environment Variables
| Variable | Required | Description |
|----------|----------|-------------|
| `NC_JWT_SECRET` | Yes | Auto-generated by Render |
| `NC_RATE_LIMIT_TIER` | No | `community` (default), `professional`, or `enterprise` |
| `NC_DEFAULT_LLM_PROVIDER` | No | `mock` (default), `openai`, `anthropic`, `google` |
| `NC_OPENAI_API_KEY` | For OpenAI | OpenAI API key |
| `NC_ANTHROPIC_API_KEY` | For Anthropic | Anthropic API key |
| `NC_GOOGLE_API_KEY` | For Google | Google AI API key |

## Rate Limiting Tiers

| Tier | Monthly Limit | RPM | Target |
|------|--------------|-----|--------|
| Community | 50 assessments | 10 | Free/open-source users |
| Professional | 500 assessments | 30 | Paid individual users |
| Enterprise | Unlimited | 120 | Organization accounts |

Set via `NC_RATE_LIMIT_TIER` environment variable. Tracked per API key.
