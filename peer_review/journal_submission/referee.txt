2.1    Grothendieck Topologies and Sites
Definition 2.1 (Sieve). Let C be a category and C ∈ C an object. A sieve on C is a collection
S of morphisms with codomain C that is closed under precomposition: if (f : D → C) ∈ S and
g : E → D is any morphism, then (f ◦ g : E → C) ∈ S.
    Equivalently, a sieve on C is a subfunctor of the representable presheaf HomC (−, C).

Definition 2.2 (Grothendieck Topology). A Grothendieck topology J on a category C assigns to
each object C a collection J(C) of sieves on C (called covering sieves) satisfying:

(J1) Maximality: The maximal sieve mC = {f : cod(f ) = C} is in J(C)

(J2) Stability: If S ∈ J(C) and g : D → C is any morphism, then the pullback sieve

                                   g ∗ (S) := {h : D′ → D | g ◦ h ∈ S}

      is in J(D)

(J3) Transitivity: If S ∈ J(C) and for each (f : D → C) ∈ S we have Rf ∈ J(D), then the
     composite sieve
                                S ◦ R := {f ◦ h : f ∈ S, h ∈ Rf }
      is in J(C)

Definition 2.3 (Site). A site is a pair (C, J) where C is a small category and J is a Grothendieck
topology on C.

Definition 2.4 (Sheaf on a Site). A presheaf F : C op → Set is a sheaf for the topology J if for
every covering sieve S ∈ J(C), the natural map

                                    F (C) −→      lim       F (D)
                                               (f :D→C)∈S

is a bijection. The category of sheaves is denoted Sh(C, J).

Theorem 2.5 (Grothendieck Topos). For any site (C, J) with C small, the category Sh(C, J) is a
Grothendieck topos: it has all finite limits and colimits, exponentials, and a subobject classifier.

Convention 3.3 (Extensional Equality). Two morphisms f, g : X → Y in Noetica are equal if

Remark 3.4 (On Pullback-Completeness). Definition 3.2 ensures that:

3.2      Concreteness and Finiteness
Proposition 3.6 (Faithful Embedding). The inclusion U : Noetica ,→ FinSet is a faithful
functor.

Proof. By Definition 3.2, morphisms in Noetica are functions in FinSet, so two morphisms are
equal in Noetica iff they are equal as functions. This is precisely faithfulness.

Proposition 3.7 (Finite Hom-Sets). For any X, Y ∈ Obj(Noetica), the hom-set HomNoetica (X, Y )
is finite.

Proof. Since X and Y are finite sets (objects of FinSet), there are at most |Y ||X| functions X → Y .
Thus |HomNoetica (X, Y )| ≤ |Y ||X| < ∞.

Corollary 3.8 (Small Category). Under Assumption 3.5, Noetica is a small category with finitely
many objects and finite hom-sets.


3.3      Pullbacks
Proposition 3.9 (Pullbacks in Noetica). Noetica has all pullbacks, and the forgetful functor
U : Noetica → FinSet preserves them:

          U (X ×Z Y ) = U (X) ×U (Z) U (Y ) = {(x, y) ∈ U (X) × U (Y ) : U (f )(x) = U (g)(y)}

Proof. By Definition 3.2, fiber products are included in Obj(Noetica) by construction, and pull-
back projections are included in the morphism class. The underlying set is the set-theoretic fiber
product by definition.

5.2     Pullback Properties
Proposition 5.6 (RPM Pullback Surjectivity). For any morphism g : J → I, the pullback P :=
J ×I R(I) along εI : R(I) → I has projection q : P → J that is surjective on underlying sets.

Proof. We construct a section ϕ : J → P of q.
    Define ϕ := ⟨idJ , R(g) ◦ ηJ ⟩ : J → J ×I R(I) using the universal property of pullback. We verify
this is well-defined by checking the pullback condition εI ◦ (R(g) ◦ ηJ ) = g:

              εI ◦ R(g) ◦ ηJ = g ◦ εJ ◦ ηJ               (naturality of ε, Remark 5.5)
                             = g ◦ idJ                   (Axiom 5.3)
                             =g

Thus ϕ is a valid morphism into the pullback.
    Since q ◦ ϕ = idJ (by definition of pullback projection), q has a section. Any function with a
section is surjective, so U (q) is surjective.

Remark 5.7 (Axiom vs Proposition). In earlier versions, RPM pullback surjectivity was stated as
an axiom. We have now derived it from the section-retraction identity (Axiom 5.3) and naturality,
eliminating redundancy.

7.1     Definition and Basic Properties
Definition 7.1 (Noetic Topos). The Noetic Topos is the category of sheaves on the noetic site:

                                   NoeTop := Sh(Noetica, Jnoe )

Axiom 7.2 (Subcanonicity). The topology Jnoe is subcanonical : every representable presheaf
y(I) = HomNoetica (−, I) is a sheaf for Jnoe .

Remark 7.3 (Justification for Subcanonicity). For a topology generated by jointly surjective families
on a concrete category with finite hom-sets, subcanonicity is a natural condition: representables
satisfy the sheaf condition because covering families “see” all of U (I). In the TKS context, this
reflects that Ideas are fully determined by their relationships.

Theorem 7.4 (Topos Structure). NoeTop is an elementary topos with:

  (i) All finite limits and colimits

 (ii) Exponentials F G for any sheaves F, G

(iii) A subobject classifier Ω

Proof. By Theorem 6.4, (Noetica, Jnoe ) is a site. By Corollary 3.8, Noetica is a small cate-
gory. By the fundamental theorem of Grothendieck topoi (Mac Lane–Moerdijk, Theorem VII.1.1),
Sh(Noetica, Jnoe ) is a Grothendieck topos, hence an elementary topos with the stated struc-
ture.
