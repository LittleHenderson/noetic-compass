## 1. INTRODUCTION

Cognitive architectures require formal foundations. Existing architectures — ACT-R, SOAR, Clarion, Sigma, LIDA, Nengo — specify cognitive processes through procedural descriptions, production rules, or neural network architectures. While these approaches have produced empirically valuable models, they lack a unified mathematical framework for reasoning about cognitive operations as composable structural transformations.

We propose a categorical specification: cognitive operations form a category, and the resulting topos structure provides a formal semantics for cognitive evaluation. The framework, called the Cognitive Architecture System (CAS), defines 10 cognitive operators (Noetics: CO-0 through CO-9) as morphisms between cognitive states, with admissibility relations constraining which state transitions are architecturally valid. The cognitive state space is the 40-element set I formed by crossing 10 Noetics with 4 Processing Domains (Principled, Cognitive, Evaluative, Operational) under a strict precedence order P ≻ C ≻ E ≻ O.

The central mathematical construction is the Noetic Topos — a Grothendieck topos Sh(C, J) of sheaves on a finite site (C, J) whose objects are finite products of the cognitive state space I and whose morphisms are operator compositions. The Grothendieck topology J is generated by covering families that contain the counit morphism ε: R(I) → I of the Recursive Prerequisite Model (RPM). The topos carries a subobject classifier Ω encoding a 3-valued intuitionistic logic — a truth-value lattice for cognitive evaluation.

This paper extracts the mathematical core from the 596-page TKS v7.4 FULL_CORRECTED manual (Chapters 1–4: The Noetic Topos, Noetic Manifolds, The Noetic Metric, Noetic Connections) and presents it as a self-contained, referee-defensible submission. Four mathematical corrections to prior versions are proved: admissibility relations as structural guards on operator composition, RPM as section-retraction (not adjunction), Noetic Coverage using the counit (not the unit), and the cognitive state space as the open probability simplex with Fisher-Rao metric.

## 2. THE NOETIC SITE

### 2.1 Objects: The Cognitive State Space

The cognitive state space I is the 40-element set formed by the Cartesian product of 10 Noetic operators and 4 Processing Domains: I = { ^n^D : n ∈ {0,…,9}, D ∈ {P, C, E, O} }.

The 10 Noetics are: ^0 (Idea), ^1 (Mind), ^2 (Positive/Attraction), ^3 (Negative/Aversion), ^4 (Vibration/Resonance), ^5 (Female/Receptive Integration), ^6 (Male/Projective Assertion), ^7 (Rhythm/Conditioning), ^8 (Above/Cause), ^9 (Below/Effect). The 4 Domains obey a strict total order: P ≻ C ≻ E ≻ O. Domain descent P → C → E → O defines the causation graph; O → P defines the feedback path.

Structural invariants: involution pairs CO-2 ↔ CO-3, CO-5 ↔ CO-6, CO-8 ↔ CO-9; self-duals CO-0, CO-1, CO-4, CO-7. The monoid (N, ∘, CO-0) has CO-0 as identity.

### 2.2 Morphisms: Cognitive Operators with Admissibility

**Definition 1 (Admissible operator application).** For CO-k (k ∈ {0,…,9}), the admissibility relation Dk ⊆ I × I specifies valid (source, target) pairs. CO-k(i → j) is admissible iff (i, j) ∈ Dk. Special case: D0 = {(i, i) : i ∈ I} — identity only on diagonal.

**Guard condition.** For composition CO-j ∘ CO-k, defined only if ∃ m ∈ I with (i, m) ∈ Dk and (m, j) ∈ Dj.

**Proposition 1.** The admissibility guard prevents ill-typed state transitions.

*Proof.* CO-j ∘ CO-k(i → j) requires intermediate state m with both admissibility conditions. Without the guard, the monoid product would admit transitions not sanctioned by the cognitive architecture. ∎

### 2.3 Composition

The operators form a monoid (N, ∘, CO-0). Composition is defined segment-wise with the admissibility guard. Monoid axioms hold for admissible applications.

### 2.4 The Finite Site

Objects of C: all finite products I^n = I × … × I (n ≥ 1). Morphisms of C: all finite compositions of CO-k morphisms and product projections, closed under pullback. C is the smallest pullback-complete subcategory of FinSet containing the 10 CO-k morphisms. Pullback-completeness guarantees composition closure structurally — no case-by-case verification across 10×10 = 100 operator pairs required.

### 3.2 The Noetic Coverage (Noe-Cov-3)

**Definition 2 (RPM embedding and realization).** η_I: I → R(I) — embedding: η_I(i) = (score(i), score(i)², √score(i)), verified at cas-engine/src/rpm/mod.rs:59. ε_I: R(I) → I — realization: ε_I(a, b, c) = a.

**Theorem 1 (Section-retraction identity).** ε_I ∘ η_I = id_I. η_I ∘ ε_I ≠ id_R(I).

*Proof.* η_I(i) = (score(i), score(i)², √score(i)). ε_I extracts first component: ε_I(η_I(i)) = score(i) = i. For reverse: s₁ = (a,b,c), s₂ = (a,b',c') distinct → ε_I(s₁) = ε_I(s₂) = a → η_I(ε_I(s₁)) = (a,a²,√a) ≠ s₁,s₂. ∎

**Corollary 1.** RPM is section-retraction, not adjunction. Prerequisite satisfaction is one-directional.

### 3.3 Coverage Direction

**Definition 3 (Noe-Cov-3).** Covering families contain ε_I: R(I) → I. Direction: TOWARD covered object.

**Theorem 2.** Using η instead of ε would trivially satisfy coverage but not generate I topologically.

*Proof.* ε is split epimorphism (ε∘η = id), hence surjective → generates covering sieves. η is split monomorphism, image = diagonal embedding, not maximal (η∘ε ≠ id ⇒ R(I) strictly larger). ∎

## 6. THE NOETIC METRIC

### 6.1 Fisher-Rao Metric

**Definition 4.** g^FR_p(u,v) = Σ_{k=0}^{39} (uk·vk / pk).

**Definition 5.** d(p,q) = 2·arccos(Σ√(pk·qk)), where the sum is the Bhattacharyya coefficient BC(p,q).

**Theorem 3.** (S°_I, d) is a metric space.

*Proof.* **Positive-definiteness:** g^FR_p(u,u) = Σ(uk²/pk) ≥ 0, equality iff u = 0 (pk > 0). **Symmetry:** g^FR_p(u,v) = g^FR_p(v,u). **Bilinearity:** g^FR_p(au+bv, w) = a·g^FR_p(u,w) + b·g^FR_p(v,w). **Triangle inequality:** Embed φ(p) = (√p0,…,√p39) into unit sphere S^39_+. Then d(p,q) = 2·d_S(φ(p), φ(q)). Spherical distance satisfies triangle inequality → d inherits it. **Non-degeneracy:** d(p,q) = 0 iff BC(p,q) = 1 iff pk = qk ∀k (Cauchy-Schwarz equality condition). ∎

### 6.2 Geodesic Distance

d(p,q) ranges from 0 (identical states) to π (maximally distant). BC(p,q) provides principled cognitive similarity measure — differences in low-probability components are weighted less than differences in high-probability components.
