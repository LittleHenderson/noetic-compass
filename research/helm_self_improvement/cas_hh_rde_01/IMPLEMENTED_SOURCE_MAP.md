## Actual captured path

`pointer_inputs.read_packet` -> initial normalized node encoding -> each actual
`_rounds` input/update/normalized state -> final node/query/pointer representations
-> `node_head`, Reach ABSENT/DIRECT and candidate-node dot products -> original
slot scores -> decisions -> assembled answer. The original `_rounds.observe`
callback is preserved. Parts/Reach do not infer a dependency on `world_head`.

The contract contains 14 named sites. Three graph-round sites must fire once
per registered round. Parts excludes the two Reach-only sites. Coordinates
include site, call, round, shape, checkpoint/input/source, signed values and
explicit meaning. Learned output/state coordinates are not called neurons.
Coordinates are within one checkpoint only. CAS labels remain
`UNKNOWN_NOT_FITTED`; transferred probe coefficients are not loaded.

Capture defaults OFF. Missing calls, extra calls, wrong shape/round, unsupported
source, missing checkpoint, wrong packet, exhausted limits and capture errors
cannot produce a complete receipt. The context removes its instance bindings
on every normal or exceptional exit. Active changes are rejected by this
passive adapter; Claude owns the separately validated intervention layer.

## Bounded witness and acceptance boundary

`aws_worker.py` reuses the existing validation transport and legacy dependency
bootstrap. It runs 18 focused tests and, if they pass, six real forwards:
OFF/OBSERVE_ONLY/NO_OP_CONTROL for one public Parts and one public Reach input.
Selection is fixed lexicographically before any prediction. This is engineering
replay, not independent confirmation, task accuracy or a causal study. No gold
answers are loaded by the diagnostic. No HELM optimizer update occurs.

Each condition freshly restores the same parent. Predictions including scores,
post-state and counter/cache deltas must match exactly; weights, AdamW, encoder,
RNG, cursor and revision must remain unchanged. The learner's normal `predict`
switch to eval mode and normal counters are compared against OFF, not concealed.
The original parent file is hashed again. Interrupted caller cleanup is checked.

Two observed receipts then pass through the actual Harness local packet/hash
log and incumbent host ledger. A fresh process receives the policy and retained
record hashes from the outer operator, not from the candidate/receipt itself.
It validates those external anchors, native provenance, packet and capture
hashes, and returns only read-only projections. There is no full neural repair
episode, active intervention or scientific acceptance claim in this first job.
