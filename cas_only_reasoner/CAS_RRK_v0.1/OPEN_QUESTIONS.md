# OPEN QUESTIONS — CAS-RRK v0.1

Every item here is an OPEN-SEMANTICS point: frozen as a question, never
silently invented. The kernel implements none of them; each is resolved
by a future gate decision.

1. **Canonical operator set.** Does CAS-RRK v0.1 admit only the canonical
   CAS-PCBA Noetics (^0 through ^9) or the broader experimental TKS
   operator set? Phase 1 admits the canonical ten only; extended TKS
   operators remain quarantined.

2. **Root Desire label.** The book and TKS v7.4 use A0; TKS v6.1 uses A1;
   A22 appears nowhere in any checked source (22 is a count). The kernel
   uses A_root internally. Freezing the canonical label is Gate 0 of the
   wider program.

3. **Foundation ontology provenance.** The 7 Foundations x 4 Worlds = 28
   sub-foundations and the 22 acquisitions are TKS-side structures, not
   stated in the three CAS PCBA sources. The kernel's machine state
   carries foundation_state as typed fields, but Phase 1 reasoning does
   not depend on the 28-channel values.

4. **Breakdown involution.** The book defines four CJT regions, and the
   breakdown region flips the output to its involution Noetic pair.
   Phase 1 models breakdown as a fault-flagged, bounded region; the
   involution-flip semantics are deferred.

5. **Counterfactual / hypothetical branches.** ASSUME-style conditional
   proof has no Phase 1 semantics. Fixtures requiring it must expect a
   typed refusal.

6. **Numeric and probabilistic reasoning.** No arithmetic evaluation, no
   counting, no probabilities in Phase 1. Comparisons of magnitudes are
   admissible only when supplied as propositions.

7. **Procedural and constitutional learning.** Durable write-back exists
   only from committed outcomes with sealed traces (episodic). Procedural
   and constitutional layers are disabled and raise typed faults.

8. **RPM depth policy.** Recursion depth is bounded by budget, not by
   a hard-coded level. The exact budget semantics (BUDGET_EXHAUSTED) are
   part of the conformance plan.

9. **CAS-Ohm instrumentation interface.** CAS-Ohm is not part of
   normative transition semantics. An optional instrumentation interface
   is a later, separate artifact.

10. **Compiler integration.** Stage 2 (shared CAS Kernel IR) is deferred;
    the Phase 1 kernel consumes typed problem packets directly, not
    CCDL or TKS source.
