# Initial integration decisions

The selected executor is the existing compound runtime. It already owns two-level prerequisite acquisition,
exact return, checked effects, commitment and replay. Keep that coordinator authoritative; do not nest a second
RC01 commit controller around it. Reuse the reference controller's proposal/measurement contracts where compatible.

The first missing executable connection is a typed allocation grant to the existing host step, followed by an
independently read execution-event measurement and a snapshot-bound return-address projection. Existing PCBA parsing
and Ohm design calculations do not supply that connection by themselves. A zero grant or disabled actuator must
produce zero native calls even if its displayed prediction is positive. Native charged budgets remain separate.

Use one native transition attempt per observation window as the first bounded control unit. Record instructions,
checker work, rejected work and overhead separately; this is not calibrated human attention. Without diagnostic
eligibility, ASOM stays UNASSESSED. No component name or design PASS may grant native commit authority.

Source paths were resolved from exact Git trees and the existing shared-module inventory tool. The two public Ohm
facades live under noetic-compass-scaffold/noetic-compass/api/, not the repository-root api/ directory. Sparse
absence was not treated as missing implementation. The original directive/package and prior jobs remain unchanged.

T01 source pins and T02 contract choices are prepared here; their executable acceptance remains NOT_RUN. Actual
adapter code, complete closed-loop witness and nested trace are the next task. No neural claim or full-lane completion
is made. All project tests, including CPU runtime tests, go to Claude's bounded AWS runner under the owner preference.
