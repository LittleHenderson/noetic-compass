```
commitment either accepts or rolls it back
```

The explicit chain-tag system should remain the accountability baseline. The phase mechanism should remain optional and experimental.
Prior phase experiments showed why. The phase engine could improve retrieval while collapsing the identity of separate reasoning chains, which triggered PHASE_MEMORY_UNSAFE.  At convergence, the earlier oscillator also tended toward global synchrony, causing distinct chains to merge rather than remain separately attributable. 
So the safest architectural hierarchy is:
```
chain ID:
guarantees which train of thought owns an activation

pulse amplitude:
represents current relevance inside that chain

optional phase/frequency:
coordinates temporal behavior inside the chain

verifier:
checks the retrieved memory

coordinator:
authorizes whether it enters Bias or learning
```
The pulse should help retrieval. It should never be the sole authority for chain identity.
