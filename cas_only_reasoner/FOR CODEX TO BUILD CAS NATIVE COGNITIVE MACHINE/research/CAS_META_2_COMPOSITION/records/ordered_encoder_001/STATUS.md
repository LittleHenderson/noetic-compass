# Ordered encoder correction - source preparation

The existing problem encoder has a verified information-loss defect. On valid
REACHED_VIA graphs, reversing a directed edge, swapping query roles, or replacing
a query label with an unseen lexical anagram can leave its algebraic input
unchanged while the checker answer changes. The retained pure audit contains
96 changed-answer collisions and 32 graph-line-reorder controls across 16
label sets and two prompt styles. Identical real-arithmetic expressions do not
assert bitwise equality of floating-point reductions. GPU measurement is a
separate gate.

`real_framework.py` remains byte-identical to the earlier published experiment.
Its comments claiming role-sensitive complete pairings are contradicted by these
counterexamples. The original contrast result is preserved: this new diagnosis
establishes a representational defect, not the cause of every earlier wrong answer.

The new opt-in ordered encoder preserves the train-fitted tokenizer, frozen
projection, option path and model width. Position-specific signed coordinate
permutations replace the commutative pooling. There are no learned parameters,
private-target inputs or graph-answer solver in the encoder. Its profile identity
explicitly rejects silent use as the historical checkpoint encoder. Finite-width
encoding is still lossy; removing a known forced symmetry is not a proof of
universal collision freedom, learned transfer or native routing.

The completed complementary/perspective archives remain preserved build-only
artifacts. Their software checks still stand, but their inherited input encoding
now has a known scientific limitation. They must not be treated as evidence of
a corrected representation or launched as a corrected experiment without an
explicit versioned profile and matched comparison.

Next numeric gate: one bounded, zero-update AWS encoder diagnostic compares the
actual old/new vectors on all declared pairs, checks line-reorder parity and
verifies unchanged frozen projection bytes. It constructs no learner and loads
no model checkpoint. Maximum inner runtime is 1,200 seconds; planned one-job
reservation is $7, with no automatic retry. A failure remains a failed gate.

The complete project vision remains open. After this prerequisite, the direct
integration priority is the kernel-governed missing-skill/acquisition/qualified
installation/exact-parent-resume/restart/rollback episode described in
../vision_continuation_20260916/INTEGRATION_GAPS.md. An encoding repair cannot
substitute for that episode, learned program synthesis, native flow integration,
multimodal competence, or the remaining V01-V18 and 31-system requirements.
