REACHED_VIA graphs, reversing a directed edge, swapping query roles, or replacing
a query label with an unseen lexical anagram can leave its algebraic input
unchanged while the checker answer changes. The retained pure audit contains
96 changed-answer collisions and 32 graph-line-reorder controls across 16
label sets and two prompt styles. Identical real-arithmetic expressions do not
assert bitwise equality of floating-point reductions. The completed GPU result
above supplies the separate numeric gate.

`real_framework.py` remains byte-identical to the earlier published experiment.
Its comments claiming role-sensitive complete pairings are contradicted by these
counterexamples. The original contrast result is preserved: this new diagnosis
establishes a representational defect, not the cause of every earlier wrong answer.

projection, option path and model width. Position-specific signed coordinate

encoding is still lossy; removing a known forced symmetry is not a proof of
universal collision freedom, learned transfer or native routing.
