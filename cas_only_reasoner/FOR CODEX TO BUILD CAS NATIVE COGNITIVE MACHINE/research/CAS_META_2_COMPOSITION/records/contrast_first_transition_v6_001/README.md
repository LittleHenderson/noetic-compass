# v6 error diagnostics

Prepared before reading this run's held-out results. The reporter requires an
externally hash-bound completed stored semantic audit and result archive.
No completed-result receipt exists yet; synthetic tests do not prove it works
on a real v6 packet.

Complete-task results retain all attempted tasks in their denominators and
are grouped by actual depth and test condition. Failed generations remain
failures, even when they have no executable trajectory.

Supplementary input and child-selection counts compare the literal named
procedure/step sites described by each task. Missing expected sites count
wrong. These are not replacements for the frozen semantic task score and
can penalize a semantically equivalent renaming.

First-error diagnostics reuse the previously corrected trajectory comparison.
They identify the first recorded divergence from a successful rule trajectory,
not the earliest neural decision or a proven causal explanation. A rejection
before execution has no executed transition. Multiple labels can describe one
divergent transition.

The 72 test cases are 24 related triplets: novel depth-3 programs with familiar
wording, the same programs with withheld wording, and matched deeper depth-4
programs. They are not 72 independent structures. Actual source and data
identities must be verified before reporting this run as evidence.

rejected its long working-directory path (`WinError 267`). The corrected runner
uses the shorter META2 working directory and retains its results in
`pure_checks_002`; the empty first output directory is left untouched.
