# Full public input and typed answer interface v0.1

This extension adds a reversible input format, a training-fitted text tokenizer
and deterministic scalar reference decoding. The neural encoder, learned
decoder execution, optimizer, numerical cost checks and matched study remain
separate work. Read records/typed_interface_001/STATUS.md for the accepted run
and any superseded attempts. No earlier CUDA or learning receipt certifies this
new interface.

## What reaches the learner

input_frames.py encodes every public world, declaration, node, edge, completeness
rule, source-order field, question, instruction, role catalog and legitimate
worked support. Shared policies are stored once in an explicit table. World and
local node aliases are reversible. Alias tables, scope labels and byte bindings
are inside the text itself; metadata alone does not carry omitted lesson facts.
Decoding the text reconstructs the complete canonical source and record bytes.

The frame validates closed syntax and internal references. This does not
authenticate source authorship, assert external-world truth, certify a worked
answer or admit an arbitrary caller's course. The worker must bind the exact
approved registry and source identities. Only the closed model_packet projection
is used here; private course lineage is not part of the learner's frame.

## Tokenization and limits

tokenization.py uses a separately versioned lexical-unit vocabulary with exact
UTF-8 byte fallback. It fits only the hash-bound public training frames supplied
by the acceptance runner. It neither reads main-query targets nor fits development
or final questions. Repeating lessons does not repeat the fitted vocabulary;
all 1,152 exposure occurrences remain in the schedule.

Every token count includes the frame start/end markers and the complete rendered
text. Overflow is refused, never truncated. Unknown lexical units are checked
against available capacity before expanding byte tokens. Raw-text, unit and
vocabulary limits are explicit. A roundtrip proves text preservation only;
the old encoder's three-option input and checkpoint profile remain incompatible.
Self-reported tokenizer metadata does not authenticate training membership;
the acceptance runner supplies the frozen-registry custody for this stage.

## Allowed answers and deterministic assembly

slots.py covers all eight answer kinds with a proposed fixed vocabulary of 90
symbols. It keeps every bank world and every declared reference available.
Node membership includes all focus nodes; edge membership includes every directed
node pair, including self-pairs. Correspondence exposes every syntactic bijection
up to four nodes plus NO_MATCH. None of these choices is filtered for correctness.
Larger correspondences are refused, not scored as semantic NO_MATCH.

Roles are six independent presence/absence decisions. The output status follows
the predicted set's cardinality. Correspondence is one joint answer: mapping
scores normalize over all public bijections, then combine with the MAPPING mode
probability; NO_MATCH has its mode probability. Adding a constant to any node
score row does not change this distribution. The declared joint maximum rule
includes its mapping-count prior and is distinct from choosing mode first.
Tie rules and scalar bounds are versioned. Incorrect predictions are neither
repaired nor replaced by the private checker.

Only scalar reference scoring is implemented. A future tensor implementation
must match its declared decisions and use a single valid-set loss for complete
correspondences; independent acceptable-node marginals lose joint constraints.
The proposed membership loss averages all slots, then fields, tasks and batches.
Forced syntactic decisions must be counted separately and must not divide by
log(1). No gradient or loss implementation is accepted by this pure stage.

## Full-course sizing and next numerical gate

The sizing runner projects every record from the previously sealed training
registry. It rebuilds all nine seed/order schedules and joins them by exact
source intent and lineage to that registry. It does not rederive private answers
or claim new independently reconstructed full-course target bundles. Registry
deduplication preserves all 1,152 occurrences and 160 update groups.

Token counts and scheduled slot/core-pass totals are pure measurements and
planned accounting. They exclude future encoding reuse, evaluation, reload,
backward passes and hardware time. Identical scheduled update counts do not
establish equal actual compute. The ordinary dependency-graph order still equals
component-first under this policy; only mixed ordering supplies a distinct
curriculum-order comparison.

Next build the scoped numerical encoder and worker-only learner with fresh
frozen projection/readout/core/optimizer identities. Check loaded source bytes,
finite vectors, actual scope sensitivity, cache equality, gradients, updates,
checkpoint/optimizer/RNG/cursor restoration, and complete memory/time/call costs.
Save predictions before private scoring. Freeze learning-speed, untouched-family
transfer and delayed-retention endpoints before final evaluation. The larger
graph panel, interaction learning, temporal processes and full CNCM charter
remain open; no learning advantage follows from these pure interfaces.
