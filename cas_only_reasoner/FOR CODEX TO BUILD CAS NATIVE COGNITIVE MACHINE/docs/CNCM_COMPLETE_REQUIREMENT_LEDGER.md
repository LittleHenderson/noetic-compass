## Status vocabulary

- `IMPLEMENTED-BOUNDED`: executable, tested behavior exists, but only for the
  stated bounded contract.
- `PARTIAL`: some real executable behavior exists, but material required
  behavior is absent.
- `CONTRACT-ONLY`: a schema or specification exists without the required
  executable system.
- `OPEN-SPECIFICATION`: the charter proposes a system, but its authoritative
  implementable contract is not yet frozen.
- `ABSENT`: the required system has no implementation in the homebase.
- `OPEN-SEMANTICS`: implementation would require inventing meaning that the
  current authority contract has not frozen.

## Honest baseline

The current build is a deterministic symbolic reference demonstrator. It has:

- a single-writer transaction coordinator and versioned MachineState;
- caller-declared branches, deterministic scheduling, and branch isolation;
- bounded Horn-style modus ponens and declared transitive inference;
- bounded native equation-dependency planning and nested missing-procedure acquisition;
- scoped source correction/retraction, installed procedures and checked formal-result
  memory across externally anchored episodes, with fresh-process journal reconstruction;
- commitment gates, typed halts, sealed hash-linked traces, replay, and bundle
  verification;
- a controlled-English adapter for a small fact/rule/question grammar,
  bounded pronoun clarification, and a browser playground.
- a standalone protected CAS-Math MVP with exact integers/rationals, a frozen
  parser, checked linear-equation proofs, bounded counterexample search,
  immutable receipts, and semantic result re-execution.
- isolated language and domain-neutral cognitive-apprenticeship laboratories
  whose local receipts and versions have no kernel authority.

It does not yet implement the complete CNCM described by the source.
