# Complete typed teaching course v0.1

This extension rebuilds the authored training course and its private answer
checker. It does not implement or run the new neural decoder. No learning gain,
retention, transfer or full-machine completion follows from this preparation.

The guarded full-course run passed 248 checks with 25 unchanged input pins.
See `records/typed_course_001/STATUS.md` for exact receipts, retained failures,
all nine source-seed/order comparisons and remaining execution gates.

## Preserved curriculum

The course retains all 1,152 logical presentations, 160 update groups, 16 rounds
and 1,152 worked-support exposures. It retains 768 foundation presentations,
128 maintenance presentations and 256 component/whole supplements. All six
faces remain represented, including 96 role-recognition occurrences.

The new plan reconstructs the original source event selectors without importing
the old all-split task compilers. Tests compare selector dictionaries against
isolated original selector functions and compare order, group sizes and depths
against pinned retained training metadata. Old answer menus and private target
values are not used to author the replacement questions.

Condition-independent occurrence IDs preserve repeated exposures. Registry
deduplication saves storage; it does not delete teaching presentations. The
source construction seeds 101, 202 and 303 are curriculum configurations, not
executed model trials.

Component-then-whole and mixed grouping receive the same complete public bank,
questions, worked examples and correction meanings. The ordinary dependency
graph again produces the component-then-whole order with the current batch size.
It is not a distinct treatment that can establish a CAS-specific advantage.
Planned update/depth counts remain separate from actual measured decoder work.

## Meaning and answer correctness

The new private checker derives answers from the supplied public declarations.
It never reads old teacher labels or latent family/archetype names. It accepts
every valid full directed-graph analogy and correspondence, including symmetric
maps. It keeps first-direct-constituent reach separate from BFS immediate
predecessor reach. Wrong but syntactically valid predictions are scored wrong;
the model-facing validator neither solves nor repairs them.

Definition and setting references identify the focused world's own declaration.
An equal phrase in another world is a different scoped reference. These are
structured retrieval tasks, not evidence of general semantic understanding.

The full bank is frozen before selecting a focus. Analogy exposes every member.
Correspondence questions use a declared, training-only curriculum rule to choose
a same-archetype graph in another domain. Face 5 sometimes deliberately asks
about a known indirect constituent. These authored question distributions are
not target-balanced random samples. Target-independent answer universes must
not be confused with unbiased question sampling.

Role recognition now uses a published controlled-language grammar with explicit
source references. A private checker validates each clause and derives its role
set without receiving the authoring template or scheduled face. Complete static
edge accounts receive both roles 5 and 6. Neutral valid source references can
receive INSUFFICIENT; false or malformed claims are refused.

The clause prefixes are themselves instructional cues. A deterministic parser
can solve this bounded recognition task. Success cannot establish unrestricted
language understanding. Recognition Face 5 now always presents a direct
inventory; old recognition commentary could instead show a reach answer.
Application Face 5 preserves its old inventory-or-reach question-selection rule.
This is a new task profile, not byte-for-byte or difficulty parity with the
legacy three-choice course.

Face 2 checks the declared setting and presentation-derived participants. It
does not introduce new interaction facts. Face 6 checks a complete static
containment account. All source process orders remain null. Learning interactions
and genuine temporal processes remains part of the wider open scope.

## Construction and custody

Preparation authors the main questions and support requests before calling the
private answer checker. Positive recognition excerpts can use graph matching
during source authoring; that is separate from computing the learner's role
target. Three different-family worked supports are then enriched with one valid
example each. The chosen example is the canonical first valid answer, never a
claim that other valid answers are wrong.

The completed teaching/audit bundle is written exclusively, flushed and checked
by reading it back before main-query target derivation. It includes private
schedule lineage for audit and must not be handed wholesale to the learner.
Only the closed `model_packet` projection supplies the source, question,
legitimate role cue, fixed role catalog and worked supports. Recognition packets
have no own-face cue and no worked supports.

The standalone packet validator checks syntax, scoped references, matching
role cues and digest bindings. It does not certify a worked answer's truth or
membership in an accepted study. Full-course validation reconstructs the
curriculum and examples. A future worker must bind exact packet IDs and source
digests to the admitted registry before inference.

Source profiles cover both direct files and the nested plan source profile.
Changing a declared nested input changes cache identity. These are disk-byte
checks, not attestations of a fresh worker's imported code. Actual worker module
origins and bytes still need independent verification.

## Execution and study gates

The full 64-world source is larger than the old input envelope. Measure fresh
training-only tokenization and complete encoding/slot/forward/backward costs;
do not truncate facts or silently reuse the 1,024-token limit. The checker
supports analogy/mapping enumeration only up to four nodes. Generic ten-node
answer syntax does not admit ten-factorial computation; the larger development
panel remains an explicit extension gate.

Implement and numerically validate the typed decoder and scoped encoder, fresh
paired model/optimizer/projection initialization, checkpoint reconstruction and
saved predictions before private scoring. Freeze separate learning-speed,
untouched-family transfer and delayed-retention endpoints before final scoring.
The earlier exposed-input CUDA smokes and negative recurrence result remain
unchanged. The complete CNCM charter remains open.
