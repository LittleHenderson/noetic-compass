HOP COUNT (run-independent)
 A scoring row carries a witness ONLY when the prediction is correct (R3 m3_out.txt: (False,False) 5779, (True,True) 7421),
 so grouping each run by its own witness is circular. I therefore compute the checker's GOLD witness path myself by
 re-implementing checker.py _bfs/_reach (research/CAS_META_2_COMPOSITION/cas_meta2/typed_teaching/checker.py:115-153)
 in pure Python on the public focus world:
   DIRECT  -> path [whole, part]          -> hop 1
   VIA     -> path from the rule          -> hop = len(path) - 1
   ABSENT  -> no path                     -> group 'none'
 VALIDATION (must pass, else I fall back to the union of written witnesses as R3 did and say so):
   (v1) every witness path written in any p10 course/dev scoring row of the six runs equals my recomputed gold path;
   (v2) my recomputed gold answer (state, via) reproduces the scoring 'correct' bit for every reach row of every run
        (prediction answer.value state/via compared to my gold).

COUNTS
