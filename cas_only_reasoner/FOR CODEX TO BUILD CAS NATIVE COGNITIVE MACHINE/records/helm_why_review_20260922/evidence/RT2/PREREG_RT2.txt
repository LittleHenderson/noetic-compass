TOO LITTLE TRAINING (for the smoke): S exact > 0 and set (ii) exact > 0 at depths 1-2, with outputs varying by input -> the 128-update constant output is explained by budget.
TASK/DESIGN LIMIT at this budget: set (ii) depth-3 exact >= 25% while dev exact = 0 of 256 -> the model reconstructs seen shapes but not held-out shapes; the 0/16 reflects shape/length extrapolation under the strict bottleneck, not only budget (not proof of impossibility at larger budgets).
SHAPE TRANSFER POSSIBLE: dev exact >= 1 of 256 -> held-out shapes are reachable and the smoke's 0/16 was budget.
Mixed results (e.g. set (ii) depth-3 between 0 and 25%, dev 0) -> INCONCLUSIVE; report numbers only.
