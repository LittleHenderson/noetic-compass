STRUCTURAL QUESTION (p10)
 records = reach records in course_p10_predictions.json with answer.value.state == VIA
 C = focus-world nodes minus whole-arg and part-arg
 CN  = min-rank X in C with whole->X and X->part (undefined if none)
 RL  = max rank in C ; RF = min rank in C
 PP  = min-rank X in C with X->part (undefined if none)
 PC  = min-rank X in C with indegree>=1 and outdegree>=1 in the full focus graph (undefined if none)
 HPR = X in C with the largest participant rank value (1..3) (undefined if no participant in C)
 D_k = records with CN defined, cue k defined, CN != k
 primary = pooled over six runs (record x run); per run reported too
 INCONCLUSIVE if distinct record_ids in union of D_k < 5. A cue with < 5 distinct record_ids in D_k = untestable,
   reported, not used in verdict.
 STRUCTURAL if on every testable cue share(VIA==CN) >= 0.80 AND share(VIA==k) <= 0.30
 SHORTCUT if some testable cue has share(VIA==k) >= 0.80 on D_k
 MIXED otherwise
 secondary only: held-only, distinct questions, unique-only PP/PC, ablation files, p00.

START-POINT QUESTION (p00)
 pointers = reach records answered VIA at p00 (the via node) + parts records at p00 (each node in answer.value.nodes)
 rank-last non-argument: reach = max rank in C; parts = max rank excluding the whole arg
 chance per pointer: reach 1/(n-2); parts 1/(n-1); expected = sum; ratio = observed / expected
 pointer at an argument = not rank-last
 also: chair-literal 1/(n-2) for all pointers; registered-floor variant (rank-last overall, chance 1/n); reach-only; parts-only
 all 564 course records at p00 (primary); held-only secondary
 LOTTERY if ratio >= 2.0 in >= 4 of 6 runs; NO SYSTEMATIC BIAS if 1/1.5 <= ratio <= 1.5 in all 6 runs; else neither.
 FLOOR: 11 = oracle one-hop 7 in population U rank-last 5 in population (gate_reading.json oracle_ceilings);
   question correct = all its held records correct (evaluate_gates.py:296-298); validate by rebuilding b/c.
