What these files establish

The renderer checked the documents against caller-pinned source bytes and rebuilt each supplied lesson before displaying it. This checks source integrity; it does not authenticate the author or establish real-world truth.

The catalog is an illustrative design example. A complete inventory means complete within this authored scene. Inspection focus, the current snapshot and a hypothetical possibility remain separate.

  • Original source bundle and caller-pinned source receipt
  • Hypothetical source bundle and its separate source receipt
  • Acceptance artifact hashes and four-page browser check results
  • Delivered file hashes

Browser checks cover every displayed cube and face, source and lesson preservation, desktop and mobile layout, and zero page network requests. They do not demonstrate improved reasoning or learning.
