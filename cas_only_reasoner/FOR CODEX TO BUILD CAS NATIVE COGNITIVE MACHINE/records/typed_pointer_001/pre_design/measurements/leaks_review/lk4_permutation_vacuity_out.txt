PART A -- the facts that make some permutation claims vacuous
  (1) world vector g_w = MEAN of the final node states (DESIGN_DRAFT_v0.1 section 2.2). A mean over
      nodes is invariant under any renaming of the nodes, so every world-choice head (definition
      kind_ref/function_ref, context setting_ref, analogy world_id) is ORDER-BLIND BY CONSTRUCTION.
  (2) each node head emits one logit per node, indexed by the node's position in the sorted-ref node
      tensor, which IS the public alias N0..N9 (slots.py:55-60). So node outputs are equivariant by
      wiring; an equivariance test tests the plumbing, not the learning.
  (3) the shared decoder breaks ties by symbol order (slots.py:293: 'argmax over each slot's declared
      symbol order; first wins exact ties'), so equal logits always emit the first declared symbol.

      why: the readout index is the node's sorted-ref position, so equivariance is the wiring. Keep as an engineering test only, which is what the draft's section 5 already says.

      why: for every kind where Part B shows the private answer is name-blind, such a metric can only pass.
