## Meaning and limits

The adapter checks actual source replay, chronology, current state, caller and
saved frames, source bindings, program identity, budgets and all timeline
events. Each complete construction report is stored once and referenced by its
digest. All 420 finite construction candidates are inspectable with bounded
pages. Work records join to their actual episode and event; earlier episodes
do not become new work charges. Every proposed next action remains a proposal.

The HTML renderer checks the supplied document's shape and internal consistency.
It does not independently replay arbitrary manually edited input or authenticate
source principals. Hashes bind content, not the truth of external claims.
TEST_FIXTURE and USER_ATTESTED labels retain those evidence limits. The viewer
has no runtime state writer and no executing planner. This checkpoint measures
inspection correctness and view parity, not a reasoning or learning advantage.
