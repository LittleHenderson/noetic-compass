Registered comparisons, constructed from public graphs and domain strings only, with labels used only afterward for assessment:
1. Analogy A-name: choose lexical first bank world with a different declared domain. A-degree: same node count and sorted directed (in-degree,out-degree) multiset, different domain; choose lexical first. A-exact: enumerate all node permutations, require equality of mapped directed edge sets and different domain; choose lexical first valid world, else NO_MATCH. Report full valid-world count, semantic accuracy, candidate ranks and ties separately. Degree success would show that an inexpensive structure summary suffices on this bank; failure while exact succeeds disproves completeness of that summary. A-name success approaching A-degree would expose a weak task/name-order shortcut, not proof of learned use.
2. Correspondence C-name: pair lexical source/target node ranks when counts agree, else NO_MATCH. C-degree: enumerate rank permutations preserving every node's directed degree pair, choose lexical first, else NO_MATCH. C-exact: enumerate full directed edge-preserving permutations and choose first, else NO_MATCH. Assess all valid mappings, not only one teacher example. C-name failure but C-degree success would distinguish rank copying from structural competence; C-degree errors repaired by C-exact would show degree ambiguity.
3. Saved-score reconstruction: independently reconstruct slot IDs from stored packet_digest, grammar body and world aliases; reconstruct hierarchical whole-bijection scores, mode probability, best admissible rank, exact top ties, independent row-argmax duplication and semantic errors. Compare reconstructed winners to stored answers and independent graph correctness to saved checker correctness. A bijective stored answer that is wrong indicates semantic selection error, not duplicate-target decoding. Missing inputs or mismatch stop the affected claim.
4. Algebra check: n=2,3,4; four deterministic matrices per n (zero, column-only, identity preference, asymmetric integer scores). Compare complete-permutation normalized probabilities before versus three log row/column normalizations; tolerance 1e-12. Prediction: these normalizations subtract row and column constants shared by every permutation and therefore leave all conditional permutation probabilities unchanged, apart from rounding. A discrepancy beyond tolerance challenges implementation/proof. This does not isolate historical training gradients or the effect of replacing a column-only score with a pair score.
5. Decoder alternative: mode-first chooses NO_MATCH if mode's NO_MATCH score >= MAPPING; otherwise chooses highest-scoring bijection, tie lexical first. Compare to saved hierarchical MAP and valid sets; if it only helps NO_MATCH errors, decoding policy is a possible limited repair; if wrong mappings remain, policy alone cannot fix structural ranking. This is diagnostic on historical data, not a proposed grader change.
