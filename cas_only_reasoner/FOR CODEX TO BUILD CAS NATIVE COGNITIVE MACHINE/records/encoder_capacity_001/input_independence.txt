The constant-input row is the decisive one. With every slot given the SAME vector, any
spread at all comes from the readout's own geometry, and the commonest alias is what the
machine says when it is told nothing. If the random-input rows concentrate like the
recorded distribution, the concentration is not caused by the inputs; if they stay
spread, the inputs are doing the work and the cause lies in the encoder, which this test
does not model.
