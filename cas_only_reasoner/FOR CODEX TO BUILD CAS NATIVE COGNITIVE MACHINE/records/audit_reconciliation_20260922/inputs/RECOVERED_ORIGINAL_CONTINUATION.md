## 6. Preserve what the coordinates mean

Use the existing implementation. Do not write another coordinate transform in the browser or change the chosen denominator merely to simplify the new adapter.

The Ohm atlas's canonical profile order is Noetic-major. The engine and standalone lab may use domain-major. Retain the declared order and use the tested conversion. Neither ordering settles the Domain/Register/World translation questions.

Every numerical profile needs an explicit basis, source, ordering and origin. Native records and Helm predictions must remain unprofiled unless a justified producer supplies their forty numbers. No automatic uniform profile, guessed activation profile, or conversion of ordinary confidence values into CAS coordinates.

A reference is a complete saved profile, not the all-zero profile. Its relative coordinates become zero. That is not Noetic `^0` and not an empty state.

Inspection focus, coordinate reference, the displayed saved present, and a live machine state are distinct. Changing focus or reference does not execute a transition. Loading another recorded snapshot must explicitly identify that snapshot, preserve its predecessor and avoid claiming that the offline file became a live connection.

Exact addresses bind a complete snapshot. Persistent item IDs support identity across declared versions, but do not automatically make old exact addresses point into a new snapshot. Never silently substitute the "latest" version.

Coordinates are not a shortest-path rule, a probability of success, or a work measurement. Do not implement a new distance or routing policy as an accidental part of this adapter.
