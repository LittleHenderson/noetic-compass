# Next matched learning study: source review

The real ordered-ingestion smoke now permits planning the matched learning study.
This note is a source review, not a new frozen protocol or permission to reuse an
old launch request. It selected no final panel, opened no final target answers,
ran no learner and created no reservation.

1. Use fresh paired origins and fit tokenization only on declared training text.
   The old complementary runner (runner.py:283-317) uses the legacy face corpus,
   encoder and retained recurrent checkpoint. Both new arms must share exact
   starting model, optimizer, tokenizer and projection values under the ordered
   encoder, with source and run identities bound before teaching.
2. Make the equal-information comparison the primary decision. The old
   evaluation.py:126 rule can pass ALT against WHOLE_SUPPLEMENT when the
   equal-item ALT versus MIXED contrast fails. A component-to-whole versus mixed
   curriculum can share the same lesson multiset, corrections, batch sizes and
   measured work limits. That isolates teaching order on a shared learner; it
   does not by itself isolate CAS architecture or establish superiority over an
   ordinary dependency graph. Define that separate comparator operationally
   before making a CAS-specific claim.
3. Reuse closed public prediction packets and durable seals before private
   scoring. The old runner's public-task denylist and in-memory hash are weaker
   than the new ingestion boundary. Audit option generation: data.py:35-36 passes
   the target reach kind into final_panel._reach_options (final_panel.py:253-261).
   This does not by itself prove shortcut leakage, but it does not satisfy the
   proposed target-independent option gate without further work.
4. Freeze distinct speed, retention and transfer endpoints. Existing development
   snapshots do not define a speed criterion. Measure accuracy against actual
   examples, optimizer updates and model work; measure application performance
   before and after teaching; test retention after intervening lessons. Fresh
   random weights may have no prior competence to retain. Establish that through
   common training first, or report RETENTION_UNASSESSED instead of inventing a
   retention gain.
5. Use development data for policy and sample-size choices, then freeze the
   comparison and success rule before final scoring. The canonical six-development
   and thirty-final families remain candidate supply. Exclude the two overlapping
   perspective-derived variants and preserve the 8-10-node versus 3-4-node size
   transfer limitation. Use paired seeds and an ordinary graph control with equal
   information/budgets for any claim specifically about CAS structure.

All findings are about the current source, not an executed replacement study.
