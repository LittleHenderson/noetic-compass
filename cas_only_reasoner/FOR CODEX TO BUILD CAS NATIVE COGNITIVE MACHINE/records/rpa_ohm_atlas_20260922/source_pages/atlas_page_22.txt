Proposed application mockup. Flower shapes show nested structure; the inspector carries the authoritative type, context and evidence status.
No live application is claimed.
Concept mode emphasizes the nested-flower layout. Geometry mode displays a named coordinate system and its
limitations. Transition mode shows permitted arrows and costs. Evidence mode exposes observations, assumptions,
witnesses and conflicts.
Controls should distinguish Expand, Focus, Simulate and Recenter from observation. The last control requires an
authorized snapshot update; it is not a shortcut for treating an attractive future as actual.
Labels carry the meaning
Use relation names, node IDs, line styles and status text, not color alone. A dashed branch is hypothetical; a
recorded outcome includes its observation and verifier reference. Shared data remains linked when the view
moves.
