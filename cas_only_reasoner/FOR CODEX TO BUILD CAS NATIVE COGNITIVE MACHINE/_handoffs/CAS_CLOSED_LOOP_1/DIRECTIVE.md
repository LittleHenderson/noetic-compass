## 4. Meaning and authority contracts
A CJT proposes an Effect and a Bias update. Only the existing authorized coordinator commits them. Bias includes substrate/parameters, memory, prerequisite evidence, operating state and permissions; it is not the scalar bias of a neural layer. **RPM diagnoses missing prerequisites; ASOM describes operating condition. Neither substitutes for the other.** Keep D, W and P separately sourced, with typed evidence and invalidation rules, not normalized into one probability vector. Never turn a missing prerequisite into a passed one by changing its score without evidence. [S1, S2]
Keep `region_state`, `semantic_outcome`, `diagnostic_availability` and `readiness` separate. An active region can produce a wrong answer; a failed answer alone does not identify starvation, saturation or inversion. Use A/S/O/M only under a named versioned classification policy and sufficient measurements. Otherwise show UNASSESSED with the missing measurement. Do not force all faults into four labels. A posterior over uncertain conditions is not a measured mixture of conditions. Preserve child probes: a healthy parent average must not conceal a blocked child. [S1]
Use Noetics `^0` through `^9`. Respect the selected ontology/version for Domains, Registers, the 40-state order and the 28 labels. No new World-to-Domain/Register cast, nickname, Foundation mapping or physical-circuit law is silently introduced. Component roles must govern inputs, outputs, permitted actions or computation. A label that changes no behavior is metadata, not a demonstrated mechanism. [S1, S2]

## 5. One measurement contract and one real actuator
Create a small typed envelope around the existing implementations. Each measurement binds episode, tick, board, CJT, source event, timestamp, quantity, units/scale, origin, exact or original numeric representation, uncertainty/eligibility and policy version. Distinguish **I_predicted, I_allocated and I_executed**. Keep any measured neural activation statistic separate unless a documented calibration makes it comparable. Never rename tokens, work counts or activation norms as universally validated human attention. [S2, S3]
Use a declared operational unit for the first slice, preferably executed primitive/CJT work quanta per observation window. Meter actual execution in the executor, including rejected work, verification, retrieval and controller overhead. Reservations are not execution. Derive I_predicted from independently defined V and R; do not obtain R from the same I_executed and then call their substituted equality validation. Compute a residual only when quantity, time window, scale and measurement eligibility match. The ratio alone cannot identify a hidden cause. [S1-S3]
Use the existing exact-rational arithmetic for declared design values, reference calculations and exact boundary tests. Preserve signed residuals separately from nonnegative design quantities. Neural tensors stay in their declared floating-point format; record original values and conversion policies rather than forcing fractions into a neural hot path. Refuse NaN, infinity, zero divisors, invalid intervals, scale mismatches and unrepresentable results. Exact representation of an observation does not make the observation exact. [S3]
An actuator must perform something real: allocate additional bounded primitive work, choose a permitted retrieval path, suspend for method acquisition, select a compatible available expert, or split a task using an executable composition contract. Declare the mapping from the control request to that behavior before a trial. Start with ONE existing actuator, not an entire motor-control catalogue. The baseline controllers must have access to the same actuator. A changed JSON number with unchanged computation cannot pass actuator acceptance.
Relative allocation and total work are different. For positive ready scores, normalization may choose shares; uniform scaling leaves shares unchanged. If total flow is used, bind it to an explicit bounded total-work policy and a measured executor, not a display variable. Apply hard permission/readiness masks before ratio arithmetic. All-zero/no-ready cases produce a named no-ready result or an authorized RPM subgoal, never a uniform fallback or an execution of a prohibited branch. Integer allocation uses a declared deterministic rounding rule and cannot exceed the host budget. [S1, S2]

## 6. Preserve the runtime's tick order
The existing reference order is: READ; CANDIDATE; READINESS; ROUTE; EXECUTE; OBSERVE; VERIFY; DIAGNOSE; EMIT UPDATE INTENTS; ATOMIC COMMIT OR ROLLBACK; SEAL TRACE. Adapt to the selected current runtime without reordering its meanings. A diagnosis from this tick changes a later tick, not the route already recorded. A readiness failure may create a repair intent and suspended continuation; it does not silently execute a blocked parent in the same stage. [S2]
Each RPM frame preserves parent goal, exact input and context/version, branch, return stage, budget remainder and prerequisite signature. Detect repeated signatures and cycles. A repair has a checked postcondition, declared allowed evidence and a terminal status. Reuse satisfied prerequisites only with valid scope/version/expiry evidence. Resume the original caller, not an easier replacement task. Commit verified memory and Bias deltas atomically; invalidate stale downstream evidence when required. A rollback restores state but never refunds work already spent. [S1, S4]
Use separate execution/candidate/commit identities. A board's accepted component syntax does not imply that every component has executable semantics. Create a separate versioned execution profile for the supported board subset and refuse or preserve as unverified unsupported passive transfers, ports, feedback, macros and timing. Do not invent a circuit solver, infer total resistance from a part list, or claim global stability from an isolated loop-gain check. [S5]
