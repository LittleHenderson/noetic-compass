# CAS-Math Roadmap v0.1

The in-homebase source charter makes mathematics the first post-kernel native
learning benchmark. Delivery is staged so exact validity is established before
learning claims.

## Delivered in the bounded standalone increment

- frozen exact CAS-Math objects and parser;
- canonical rational and linear normalization;
- protected step reconstruction with immutable receipts;
- checked one-variable linear-equation proofs;
- bounded deterministic counterexample search;
- semantic re-execution verifier and negative tests.

## Next: versioned RRK integration

- freeze math workspace, intent, trace, and evidence schema versions;
- add an untrusted CCB-M1 proposal issuer;
- have the transaction coordinator rerun the protected checker;
- commit accepted math claims only through the sole writer;
- preserve rejected proposals and discarded branches as trace evidence;
- add exact replay and rollback tests for math state;
- expose manual math stepping in the playground.

## Then: mathematical learning

- record first failing proof step and fault class;
- create typed RPM prerequisite goals;
- retain M0 solved episodes after commitment;
- propose and compare M1 strategies on isolated branches;
- evaluate held-out transfer and protected regressions;
- add an M2 lemma only after exact proof verification;
- keep M3 theories explicitly versioned and M4 immutable;
- implement curriculum dependency graphs and counterexample-guided repair.

No learning milestone is complete until a retained improvement changes behavior
on held-out problems without changing the checker or protected tests.
