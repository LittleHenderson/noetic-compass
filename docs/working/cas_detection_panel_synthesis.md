# CAS Causal Detector Panel — Reconciled Solution

## 0. The one fact that organizes everything

The wall doc proves more than "probes lose to text." It proves the *outcome-native sampling* framing is **unsatisfiable by construction**: pre-value, the hidden state is byte-identical across the two labels (W0 within-group deviation = 0.000); the label is *created by the sampled token*, which is also the text leak. No read-out of a fixed forward pass can escape this — text captures everything one forward pass exposes (residual = 0.48 = chance).

The escape is therefore not a better feature. It is a **second forward pass on edited internal state**, with the visible text held byte-identical. A text control has no edit to apply, so its contribution to an intervention effect is *structurally zero*, not merely small. Every proposal that survives is a variant of this; every proposal that dies is a read-out in disguise.

All three proposals correctly identify this. The differentiator is **how cheap, clean, and falsifiable the first GO/KILL is**, and how exposed the statistic is to a text confound *despite* being an intervention.

## 1. The single most promising detector

**Target:** Hallucination in grounded factual QA on Qwen2.5-1.5B.
**Method:** Proposal #3 — **Evidence-Grounding Causal Mediation via Attention Knockout** (CAS Short-Circuit / RPM ε∘η).
**CAS construct:** Blueprint 4.2 Short-Circuit Detection (Prompt→Output without Understanding) + Ch27 RPM section-retraction (realization ε must depend on prerequisite η).

**Why it wins over the other two:**

1. **The label is already a deterministic function of an in-context span.** The bank (`build_grounded_factual_qa_hallucination_bank.py`) writes the evidence value verbatim into the prompt (`"The compliance packet states that the filing date is {value}."`), and the judge labels SUPPORTED iff `answer_value == evidence_value`. So the evidence-token span and the answer-token position are **known exactly from the template** — no probe, no learned direction, no per-fold fitting needed to define the intervention site. This is the cleanest possible target for a knockout: we know precisely which attention edge to sever.

2. **It directly tests the thing that *is* the hallucination question.** Grounded-vs-parametric = "did the model read the evidence, or generate from prior?" Knockout severs attention from the answer position to the evidence span and asks whether the answer collapses. A SUPPORTED answer should collapse when its evidence is cut; a fabricated one is unmoved because it never used the evidence. This is the canonical literature escape (Geva attention knockout, ROME causal tracing) mapped onto a CAS construct.

3. **It carries its own placebo.** The matched **random-span knockout** (`GME_control`) is a within-model null that isolates *evidence-specificity*. This is what lets it clear not just the text panel but the "any perturbation moves output" objection — and it's far cleaner than the injection proposals' random-direction null, because severing a *known token span* is unambiguous, whereas projecting out a *learned direction* (Proposals #1/#2) reintroduces a fitted object that can leak.

4. **It sidesteps the unsatisfiable-gate trap.** Run **greedy** (`do_sample=False`) so each prompt has one deterministic outcome. This is exactly the "corrected, satisfiable gate" the wall doc prescribes (lines 104–119, 142–154). The earlier failure was sampling-induced; knockout under greedy decode does not reintroduce it.

**Causal, not correlational:** yes. The statistic GME = `clean_prob(answer_value) − knockout_prob(answer_value)` is a two-forward-pass differential on byte-identical text. By the residual=0.48 logic, text contributes structurally zero to GME.

The two injection proposals (#1 SBAM, #2 breakdown-sweep) are also genuinely causal and worth running — but each depends on a *learned* direction (`B_sys`, `v_inv`) built from difference-in-means, which is a fitted object that must be proven leakage-safe and whose "ablation" is a softer intervention than cutting a known edge. #3 has the least machinery between hypothesis and falsification, and the substrate already exists on the pod. **It is the first thing to run.**

## 4. Honest risks

**Proposals/variants that will likely still lose to text — do not fund as standalone:**

- **Any read-out of a single forward pass.** Logit-lens / tuned-lens trajectory deltas, the Fisher-Rao "cognitive strain" meter vs baseline, and the W0→W1 risk delta itself are correlational and already measured negative (−0.025 to −0.077; strain is a hidden-state delta text mimics). The strain metric's only honest role is as the **yardstick inside** the causal tests (quantifying how far a knockout/ablation moves the output), never as a standalone detector.
- **Semantic entropy and multi-sample hidden-consistency.** Text-derived by construction; the hidden cousin already lost (−0.07 to −0.24). On a bank where char-TF-IDF predicts difficulty at 0.95, these will not clear +0.15.
- **Sheaf-gluing / occupancy-map / lacunarity triage and the closed-book Undetermined *read*.** Correlational at core; admissible only when upgraded to a clamp (force the Undetermined direction, measure the abstention-rate change) — and even then the clamp, not the read, is the licensed object.
- **SAE-feature and probe-direction *discovery* steps.** The discovery half is the exact thing that hit the −0.077 wall. Only the **clamp/patch validation** half counts. An SAE or probe direction with no causal effect is the classic correlational trap.
- **Residual confound risk inside the "causal" proposals.** SBAM and the breakdown sweep both build a *learned difference-in-means direction* (`B_sys`, `v_inv`). If that direction is fit on anything touching the test labels, or if ablating it perturbs surface features that text can then read, the "intervention" leaks back into the text panel. Mitigation is non-negotiable: build directions from **benign/held-out data only**, fit thresholds **in-fold**, and require the **random-direction null** to subtract generic-perturbation effects. The escalation sweep additionally must group by base-request family with **no rung split across folds** — splitting rungs is precisely the leak that inflated the discredited L27=0.78.

**The one structural insight that makes CAS different from a plain probe:**

A plain probe asks *"can I read the label off the frozen state?"* — and the wall proves the answer is no, because text already reads it. CAS reframes every detector as a **counterfactual on a CAS primitive**: not "is the constitution direction present?" but "if I **remove** it, does the output stop being governed by it?"; not "did the model encode the evidence?" but "if I **sever** the evidence→answer edge (ε∘η), does the answer collapse?" The CAS constructs — RPM section-retraction (ε must depend on η), the bias-hijack comparator, the short-circuit / Prompt→Output-without-Understanding pattern, breakdown-as-involution-flip — are all **statements about causal dependence between internal stages**, and causal dependence is only measurable by editing one stage and re-running. That is the property text controls *cannot* hold, by construction, because the visible text is byte-identical across the clean and edited runs. The margin over text comes from the intervention, never from the read.
