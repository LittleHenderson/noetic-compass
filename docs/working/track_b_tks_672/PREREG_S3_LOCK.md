### The motive block — five required elements

```
1. What final condition the actor truly wants.
2. What CLOSE-RIVAL outcome would NOT satisfy them.     <- essential
3. What obstacle prevents the true outcome.
4. What diagnostic choice reveals the motive.
5. What exact result counts as success.
```

| Boundary | Repair pattern | Behavioral test |

| **D1 vs D2** | a complete explanation/doctrine/answer must leave the central longing unresolved; success only in direct communion, nearness, participation, surrender, being-with | *perfect information but no direct relation → still unsuccessful?* Yes → `1`; No → `2` |
