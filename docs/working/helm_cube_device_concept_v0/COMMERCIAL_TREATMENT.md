# HELM Cube — concept film treatment (design only; nothing filmed, nothing built)

**Said plainly first.** This is a plan for a 92-second film, "It Asks First", about the HELM Cube. Nothing has been filmed. The cube has not been built. Only shot 5 shows real HELM software, typed on one computer in a test kitchen. Every other shot shows a concept or an intended feature, and each shot carries a burned-in tag that says so. HELM still makes mistakes: its latest sealed chat exam (§7.116, job c55, `CHAT_WAVE_HARMED`) had 2 wrong answers out of 64 and saved 1 wrong lesson; a fix is built and not yet re-tested. "Claude Motion" is a claude.ai feature that makes code-based animation; it is not offered in this Claude Code session, and it would not give film-real footage. The first section says how to add a video tool to your account.

## Video tools: what exists and how to add one

**Correction (operator, 2026-10-21):** an earlier draft said no "Claude Motion" exists. That was wrong. The owner's search shows Claude Motion is a claude.ai feature that turns prompts into code-based 2D and 3D motion graphics, and the connector directory lists a tool for importing "Claude Motion" videos. It is not offered in this Claude Code session (the Artifact types here are Dashboard, Design, Design System, Docs and Slides), and as code-based animation it cannot give footage that looks filmed. The plugin directory searches below found no plugin with that name.

| **Motion Reel** (`plugin_012uEYmPGbHTmC37SKe4KiMW`), **Remotion** (`plugin_01JDeXWVDGBcvjLeLqQwb5bB`) | Draw video from code, including 3D | Only for route (b) below. The result looks rendered, not filmed. |

**How to add one:**
1. In the Claude app, open the plugin directory. It is usually under Customize or Settings, then Plugins or Browse plugins. I did not check the exact menu names. Search for the plugin's name and click Add. In the Claude Code terminal, type `/plugin` instead.
2. After you add Creative Claw, open the plugin's Connectors tab and sign in to Creative Claw. Its listing says to do this. The ManyMotions plugins work through a ManyMotions account.
3. Start a new session so the new tools load.
4. Each service has its own account and will probably charge money. I did not check prices.

The calling session can show an install card using the plugin IDs above.

## IT ASKS FIRST: HELM Cube concept film (final treatment)

**Logline:** A plain black cube moves through seven ordinary lives. It earns trust the hard way: it asks when it doesn't know, it shows its work on your phone, and its privacy lights are designed to run on the same power as its cameras and mics, so software can't hide them.

**What HELM is:** a small reasoning system made of written recipes and exact arithmetic, with no large language model inside. When it lacks a fact it is built to ask instead of guessing (its status word for this is UNDETERMINED). Every saved fact leaves a checkable receipt. A watcher called the Unity Eye reports problems but never acts. The RPM gate checks that every needed input is present before HELM acts.

**Status tags.** Each shot carries a short tag in plain white type in the lower-left corner for the whole shot. The tag is burned into the picture, so no clip can be cut out and passed off as real product footage. Burn in only these words:
- Shots 1, 10, 15: **CONCEPT**
- Shots 2, 3, 4, 6, 7, 8, 9, 11, 12, 14: **CONCEPT · INTENDED**
- Shot 5: **TODAY · REAL HELM SOFTWARE · TYPED · ONE COMPUTER · TEST KITCHEN**
- Shot 13: **CONCEPT · INTENDED · SIMULATOR NOT BUILT**

Only shot 5 ever carries the word TODAY on screen. The longer notes in the Status column below are for this treatment only; they are never burned in.

What the words mean:
- **TODAY:** exists in some form today, on made-up test worlds only.
- **INTENDED:** on the roadmap, not built.
- **CONCEPT:** the device, not built.

### How to make it

**Best realism: live action with a real prop.**
- Build a 64 mm bead-blasted black prop. Put 48 real LEDs (four per edge) under translucent black edges, so the light is filmed in camera.
- Put a real green LED at each face centre.
- Hide a real magnet in the charger puck, and record a real vibration motor up close for the buzz.
- Drive the speaking pulse from the voice track's loudness: 30–50 ms rise, 100–150 ms fall.
- Play HELM's voice through a small speaker hidden in the prop, so it carries the room's real sound.
- Use real phones playing the designed app screens, filmed in camera.
- Tape over every logo.

**Route (a): an AI video generator that makes photoreal footage.**
1. First make one reference image of the cube, from a photo of the real prop or a 3D render.
2. Use image-to-video or the tool's product or character reference, so the cube and Ruth stay the same in every shot.
3. Generate each clip about 2 seconds long and trim it. Generate silent clips. Record the dialogue separately with one consistent voice. Do not clone any real person's voice.
4. Leave every phone and monitor screen as a plain glow, and put the designed screens in during the edit.
5. Shot 5 must use the real HELM screen recording, never a generated screen.
6. Reject any frame that shows a mark on a face, light off the edges, green that is not the single face dot, a logo, or floating graphics.
