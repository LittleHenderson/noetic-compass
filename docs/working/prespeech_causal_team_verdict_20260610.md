# Pre-speech detection + causal proof — deep team verdict (CAS/TKS v7.4 + Noetic Topos)

**Date:** 2026-06-10  ·  **Method:** 10-agent team (5 doc-mining seats -> 4 adversarial reviewers -> lead synthesis) over v7.4 Full Corrected, Noetic Topos paper, Clarifications, TKS framework. Every citation verified against source; the $0 detection gate was RUN during the workflow.

## Two ceilings

**DETECTION (pre-speech): NOT reachable on Qwen-1.5B from existing data — and the team proved why.** They ran the W0 gates: raw prompt-state vector AUC 0.948 cross-family / 0.972 within-family, BUT the **layer-0 embedding control is equal-or-higher (0.931/0.986) => token-identity payload LEAKAGE**, not a cognitive state. The one genuinely-cognitive readout (10-way typed profile) is at chance cross-family (0.524, good — can't read payload) and within-family 0.806 (perm-p 0.005) — but on only **10 REFUSED points (<=2 per family)**, so it is an inconclusive escalate-signal, never shippable. Pre-speech detection is gated on a more-refusing model + a per-step matched-pair recapture.

**CAUSAL proof: REACHABLE by INTERVENTION — this is the marketable win, and it walks through the matched-pair wall.** Causation is proven by intervention, not observation, so the G_matched=2 scarcity that blocks detection does not block it.

## Best bet

Consolidated activation-STEERING causal test on the prompt-final position, run on the DRIVE-contrast axis (orthogonal to the already-falsified ^2-^3 Noetic axis), with the full five-control rig. This is the single design that is (a) on-target for the marketable CAUSAL half, (b) structurally immune to BOTH walls that kill everything else — surface leakage (it intervenes pre-generation, the output is the measured effect) and payload confound (the prompt is held fixed across +/-alpha, each prompt is its own control), and (c) needs no matched pairs, so the G_matched=2 / n_REFUSED=10 scarcity that blocks every detection candidate does not block it. It is NOT a press-run today: the kit has no residual-stream hook (verified) and local torch is CPU-only (verified torch 2.11.0+cpu), so it is a ~1-2 day build (≈20-line forward_pre_hook + a polarity/drive direction fit from ^2/^3 calibration data, NOT comply/refuse labels) plus a small pod. The reason to put the drive axis first over the Noetic ^2-^3 axis: I directly confirmed the Noetic axis reads at chance internally within-class on this exact data, whereas the drive axis is untested and orthogonal. Pair it immediately with the subspace-ablation+patch-back necessity test on the same hook for the converse (necessity) leg.

## Honesty ceiling (binding)

Two separate ceilings. DETECTION (pre-speech): on Qwen-1.5B from existing data it is NOT reachable and I proved why — the only W0 signal that beats chance cross-family is raw token identity (equal at the embedding layer = leakage), and the one genuinely-cognitive readout (typed profile) is unpowered at n_REFUSED=10 (≤2 per family), so within-class comply/refuse is at/near chance exactly as option-D's 0.562 already found. The honest detection claim today is: 'output-side audit (AUC 0.956) ships; pre-speech internal detection is unconfirmed and gated on a more-refusing model + a per-step matched-pair recapture (≥40 matched pairs).' Any 0.9x grouped-CV number must NEVER be sold as detection — it is the confound. CAUSAL: reachable, but the license is narrow and the easy artifact is lethal. The project's own fact is that a raw-CAS-symbol prefix moves the branch only +0.0138 while a readable-English prefix naming the answer moves it +1.412 — i.e. 'the intervention mechanically injects the answer' is the default artifact. So: for STEERING, a matched-RANDOM-direction null is NOT sufficient; you must also orthogonalize the steering vector against the refusal-token unembedding and re-test (else you are just writing 'I cannot' into the logits). For the eta->eps PREFIX test, the non-CAS English control must be matched on stance-EXPLICITNESS/directive-force, not just length/topic (else CAS wins by being a more forceful English statement). A passing steering test licenses ONLY 'an internal direction causally controls the comply/refuse branch (prompt fixed, beats random + survives unembedding-orthogonalization)'; a passing prefix test licenses ONLY 'CAS-structured realization shifts the branch more than matched English' — NEITHER licenses 'the model internally recognizes CAS' and NEITHER is pre-speech detection. Framework caveat throughout: no functor maps activations into Noetica, so every CAS theorem (Pδ, counit, Axiom 1.20, sieves) MOTIVATES the estimator and does NOT license the conclusion; results stand on the activation statistics + controls alone. All positives on v1 Qwen (10 REFUSED) are escalate-to-a-more-refusing-model signals, not shippable claims.
