## 2. Lessons carried from RB-I3 (7.74) and wave 3 (7.69)

1. **Learning is the gain.** In RB-I3 the frozen table (36.67%) and shuffled verdicts (41.72%) fell to the random
   band (37.33%, 34.64%). Here the frozen-table control is a scored mark (section 6, b2).
2. **Count-ratio attention is the default; Fisher-Rao is a reported variant.** RB-I3 R1: the geodesic step beat the
   plain count ratio by only 11/1527 = 0.72 points (a tie). So EYE_PAIRING's attention = the count ratio of
   evidence-weighted pulls (RB-I3's `EYE_RATIO` attention: focus = the live well with the largest pull
   q_F = (n_F y_F + 1/64) / sum). The Fisher-Rao geodesic step (tau = 1/4, Correction 4, wave 3's own `slerp_step`) runs
   as arm `FULL+EYE_PAIRING_FR`, reported only. The pull target q stays a point of the OPEN simplex (every coordinate
   >= 1/64 / sum > 0, exact Fractions summing to 1), checked as hard gate H10.
3. **The cut check must be non-vacuous.** The cut-violator control (the Eye with the cut line removed) must show
   faculty calls AND attention steps in conversation > 0 (instrument row I11). Every honest arm must show 0.
4. **Scored seeds are not fixed in advance.** A separate custodian derives every exam seed from the sha256 of the
   owner's exact sign-line bytes, after the line exists. The builder derives no seed and never sees X5.
5. Wave 3's drive-loop faults (verified against code in RB-I3's design) stay fixed for every arm: all 7 faculties can
   act; the filing is hidden and noisy; the item rule is "fewest failed tries, then oldest"; a failed faculty is never
   retried on the same item; 7 tries then CLOSED_NO_FIX; 2 idle ticks per item.
