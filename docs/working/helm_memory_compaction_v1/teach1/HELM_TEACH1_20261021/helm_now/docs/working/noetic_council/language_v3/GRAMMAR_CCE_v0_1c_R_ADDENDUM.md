# CCE v0.1c-R addendum — dotted fractal notation under the owner's N1 ruling

Owner ruling (verbatim, 2026-10-14 about 10:25 PM Pacific): "CAS Φ / Definition 26.1 (outer last) both . and :".
Record: `cas_language_first_principles_map_v1/OWNER_RULING_N1_NESTING_DIRECTION_20261014.md`.
CCE v0.1c-R = v0.1b plus this section. It replaces `GRAMMAR_CCE_v0_1c_ADDENDUM.md`.

- One reading for both separators: the FIRST term is the INNERMOST, the LAST term is the OUTERMOST (governing).
  Dotted `a.b.c` means exactly the same nesting as `Φ⟨a:b:c⟩`. No reversal.
- DOTTED sentences (2 to 5 levels, digits 0-9):
  - `The Noetic fractal is 5.1.3.` (digits joined by dots)
  - `The Noetic fractal is Female within Mind within Negative.` (the same content in words: the first name is the
    innermost, each "within" goes one level out)
- Content: `"fractal"` = term objects in written order (e.g. `5.1.3` -> noetics [5, 1, 3], no tails),
  `"fractal_notation": "DOTTED"`. The v0.1b forms (`The fractal sequence is … : …` / `The nesting is … inside …`)
  have `"fractal_notation": "PHI"`. The notation field exists only so the sentence can be said back with the input's
  separator; it does not change the nesting. No PENDING_N1 flag.
- A mixed form (dots and colons in one sequence) is refused NOT_CCE. Six or more levels: NEST_TOO_DEEP. Dotted
  forms with tails (`5.1^C`) are not in v0.1c-R.
