### `cmb_ccdl_circuit_body_has_no_parser`

### `cmb_tie_breaking_resolution_floor`

For a device whose read path is 'pick the closest cell', the smallest resolvable distance is the tie-breaking floor. Measure it in both open-simplex implementations.

- Hoped `both implementations resolve arbitrarily small differences`, observed `rust d(v,v)=8.941e-08 (not exactly 0); python d(v, v+1e-12)=0.000e+00 (short-circuits to 0)`.
- Block: `B_behavioural`
- **Disposition:** MEASURED AND RECORDED, NOT WAIVED. Two opposite artifacts of the same arccos-near-1 sensitivity. The Rust engine cannot certify d=0: for identical vectors the Bhattacharyya coefficient rounds just under 1 and arccos amplifies it. The scaffold Python short-circuits when |1-BC| < 1e-12 (geodesic_memory.py:83), so it returns exactly 0.0 for identical vectors AND for genuinely different ones inside that window. Neither is a bug for belief retrieval; both matter for a 40-cell bank where near-ties decide which memory is recalled. Chapter 21 should state a minimum cell separation. No code change made by this eval.

### `cmb_cjt_fisher_rao_accepts_closed_boundary`

`cas_forex/cjt_differential.py:55` normalizes its inputs and only rejects NEGATIVE entries, so it silently accepts simplex-boundary vectors containing zeros - exactly the vectors Chapter_21:98 forbids as addresses.

- Hoped `rejected`, observed `accepted, returned 3.141593`.
- Block: `B_behavioural`
- **Disposition:** SCOPE NOTE, NO CODE CHANGE. Recorded so that a future CMB build does not reach for the nearest available Fisher-Rao function.
