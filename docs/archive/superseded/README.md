# Superseded sources — provenance only

Nothing in this directory is CAS canon. It is retained so the lineage of the
framework stays inspectable, not so it can be cited.

**Authoritative sources are, in order:**

1. `docs/CAS_FOUNDATIONAL_CLARIFICATIONS.md` — normative. Read this first.
2. `CLAUDE.md` — the working summary of canon.
3. `_tmp_TKS_v7_4_FULL_CORRECTED.txt` — TKS v7.4, the current manual.

## Why this directory exists

The CCB-R1 audit (`docs/working/cas_pcba_reasoning_audit_2026_08_27.md`) found
that a superseded manual sitting at the repository root was being read as a
primary source. Its tables contradict current canon on the Noetic numbering and
the Foundation labels, and it **misled four of six independent audit lenses and
the lead auditor twice** before verification caught it.

Anything told to "read TKS as source" will import that drift unless the
superseded material is clearly marked. Hence this directory and the warning
headers.

## If you are an agent reading this

Do not quote the files here as canon, and do not reconcile CAS artifacts against
them. If a task tells you to consult TKS, use `_tmp_TKS_v7_4_FULL_CORRECTED.txt`
and check any Noetic or Foundation claim against
`docs/CAS_FOUNDATIONAL_CLARIFICATIONS.md` before acting on it.
