\chapter{Catalogs}\label{appA:catalogs}

This appendix collects the reference tables cited throughout the monograph. All
identifiers are reproduced from the implementation's diagnostic module and the
Gate~4 candidate specification; none is invented here. The governing status
remains \textsc{draft / open / ring 4 / not licensed / held}: these catalogs
describe a research candidate's software contracts, not a certified language,
safety mechanism, or product.
